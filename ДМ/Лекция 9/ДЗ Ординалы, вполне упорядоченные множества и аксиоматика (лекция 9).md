### Ответы на Блок 1 (Контрольные теоретические вопросы)

#### Ответ на Вопрос 1.1
- **Определение WOS**: Линейно упорядоченное множество $(X, \le)$ вполне упорядочено, если любое непустое $S \subseteq X$ содержит наименьший элемент: $\exists m \in S \; \forall x \in S (m \le x)$.
- **Доказательство эквивалентности**:
  - $(1 \implies 2)$: Пусть существует бесконечная строго убывающая цепь $x_1 > x_2 > x_3 > \dots$ Рассмотрим подмножество $S = \{x_n \mid n \in \mathbb{N}\} \subseteq X$. По условию (1) у $S$ есть наименьший элемент $x_k \in S$. Но по определению цепи $x_{k+1} \in S$ и $x_{k+1} < x_k$, что противоречит минимальности $x_k$. Противоречие.
  - $(2 \implies 1)$: Пусть выполнено (2), но существует непустое подмножество $S \subseteq X$ без наименьшего элемента. Возьмём произвольный $x_1 \in S$. Так как $x_1$ не наименьший, найдётся $x_2 \in S$ такой, что $x_2 < x_1$. Так как $x_2$ не наименьший, найдётся $x_3 \in S$ такой, что $x_3 < x_2$. Продолжая по аксиоме выбора, строим бесконечную цепь $x_1 > x_2 > x_3 > \dots$, что противоречит (2).

#### Ответ на Вопрос 1.2
1. **Транзитивное множество**: $\forall x \in T (x \subseteq T)$.
   - Пример транзитивного множества: $T = \{0, 1, 2\} = \{\varnothing, \{\varnothing\}, \{\varnothing, \{\varnothing\}\}\}$. Здесь $\varnothing \in T$ и $\varnothing \subseteq T$; $\{0\} \in T$ и $\{0\} \subseteq T$.
   - Пример нетранзитивного: $A = \{\{1\}\}$. Элемент $\{1\} \in A$, но $\{1\} \not\subseteq A$ (так как $1 \notin A$).
2. **Ординал по фон Нейману**: Множество $\alpha$, которое транзитивно и вполне упорядочено отношением принадлежности $\in$.
3. **Явный вид**:
   - $0 = \varnothing$
   - $1 = \{0\} = \{\varnothing\}$
   - $2 = \{0, 1\} = \{\varnothing, \{\varnothing\}\}$
   - $3 = \{0, 1, 2\} = \{\varnothing, \{\varnothing\}, \{\varnothing, \{\varnothing\}\}\}$
   - $4 = \{0, 1, 2, 3\}$
   - $\omega = \{0, 1, 2, 3, \dots\} = \mathbb{N}_0$.

#### Ответ на Вопрос 1.3
1. Сложение $\alpha + \beta$ означает порядок на $A$, за которым следует порядок на $B$.
   - $1 + \omega$: один изолированный элемент, за которым следует бесконечная цепочка: $\bullet, 0, 1, 2, 3, \dots$ Биекция $f(\bullet) = 0, f(n) = n+1$ сохраняет порядок $\implies 1 + \omega \cong \omega$.
   - $\omega + 1$: бесконечная цепочка, за которой следует изолированный элемент в конце: $0, 1, 2, 3, \dots, \bullet$. В этом множестве есть максимальный элемент $\bullet$, которого нет в $\omega$. Значит, $\omega + 1 \not\cong \omega$, $\omega + 1 > \omega$.
2. Умножение $\alpha \cdot \beta$: замена каждого элемента $\beta$ копией $\alpha$.
   - $2 \cdot \omega$: цепочка из пар элементов: $(\bullet, \bullet), (\bullet, \bullet), \dots$ Порядковый тип — просто счётная цепочка элементов без максимального, изоморфно $\omega$.
   - $\omega \cdot 2 = \omega + \omega$: две последовательные бесконечные копии $\omega$: $0, 1, 2, \dots, 0', 1', 2', \dots$ Элемент $0'$ строго больше всех чисел первой цепочки, чего нет в $\omega$. Значит, $\omega \cdot 2 > \omega$.

#### Ответ на Вопрос 1.4
1. **Парадокс Рассела**: $R = \{x \mid x \notin x\} \implies R \in R \iff R \notin R$.
2. **Парадокс Кантора**: Множество всех множеств $V \implies \mathcal{P}(V) \subseteq V \implies |\mathcal{P}(V)| \le |V|$, но по теореме Кантора $|\mathcal{P}(V)| > |V|$.
3. **Парадокс Бурали-Форти**: Множество всех ординалов $\mathrm{On}$ само является ординалом $\Omega \implies \Omega \in \mathrm{On} = \Omega \implies \Omega < \Omega$.
- **Разрешение в ZFC**: Аксиома выделения $\{x \in A \mid P(x)\}$ требует задавать объемлющее множество $A$. Рассуждение Рассела $R_A = \{x \in A \mid x \notin x\}$ лишь строго доказывает, что $R_A \notin A$. Это опровергает существование универсального множества всех множеств, устраняя противоречие.

#### Ответ на Вопрос 1.5
- Метод Тьюринга–Флойда: строится функция $\mu: \text{States} \to \alpha$, сопоставляющая состоянию программы ординал. Доказывается, что любой шаг программы $S \to S'$ строго уменьшает меру: $\mu(S') < \mu(S)$. По критерию фундированности бесконечного спуска ординалов не существует, следовательно, программа завершится за конечное число шагов.
- Игра «Гидра»: каждому дереву сопоставляется ординал $\alpha < \varepsilon_0$. Срез любой головы уменьшает ординал. Хотя дерево может колоссально разрастаться на каждом шаге, ординал строго монотонно убывает, поэтому игра обязательно заканчивается победой Геркулеса. Недоказуемость в PA следует из того, что функция длины игры растёт быстрее любой доказуемо тотальной рекурсивной функции в арифметике Пеано (быстрее функции Аккермана).

### Решение к Блоку 2

#### Задание 2.1
1. $A = \{1 - \frac{1}{n} \mid n \in \mathbb{N}\} = \{0, 1/2, 2/3, 3/4, \dots\}$:  
   Последовательность строго возрастает: $0 < 1/2 < 2/3 < \dots$ Любое непустое подмножество имеет минимальный элемент (он соответствует минимальному номеру $n$). Бесконечного спуска нет. Множество **вполне упорядочено** (порядковый тип $\omega$).
2. $B = \{\frac{1}{n} \mid n \in \mathbb{N}\} = \{1, 1/2, 1/3, \dots\}$:  
   Последовательность строго убывает: $1 > 1/2 > 1/3 > \dots$ Образует бесконечный спуск, подмножество $B$ не содержит минимума в себе. Множество **не является вполне упорядоченным**.
3. $C = A \cup \{1\} = \{0, 1/2, 2/3, \dots, 1\}$:  
   Все элементы $A$ строго возрастают к 1, а 1 — максимальный элемент. Любое непустое подмножество, содержащее точки из $A$, имеет наименьший элемент в $A$. Если подмножество состоит только из $\{1\}$, его минимум равен 1. Бесконечного убывающего спуска нет. Множество **вполне упорядочено** (порядковый тип $\omega + 1$).
4. $D = B \cup \{0\} = \{0\} \cup \{1, 1/2, 1/3, \dots\}$:  
   Хотя точка 0 является минимумом всего множества $D$, само подмножество $B \subset D$ не содержит своего наименьшего элемента (инфимум $0 \notin B$), и последовательность $1/n$ бесконечно убывает. Множество **не является вполне упорядоченным**.

#### Задание 2.2
1. **Порядковый тип $\omega$**:  
   Перемежаем положительные и отрицательные числа:
   $$0 \prec 1 \prec -1 \prec 2 \prec -2 \prec 3 \prec -3 \prec \dots$$
   Биекция: $f(0) = 0$, $f(n) = 2n-1$ для $n > 0$, $f(-n) = 2n$ для $n > 0$.
2. **Порядковый тип $\omega + \omega$**:  
   Сначала все положительные с нулем, затем все отрицательные по возрастанию модулей:
   $$0 \prec 1 \prec 2 \prec 3 \prec \dots \prec -1 \prec -2 \prec -3 \prec \dots$$
3. **Порядковый тип $\omega + 1$**:  
   Сначала все числа, кроме одного (например, нуля), по типу $\omega$, а ноль ставим в самый конец:
   $$1 \prec -1 \prec 2 \prec -2 \prec 3 \prec -3 \prec \dots \prec 0$$

### Решение к Блоку 3

#### Задание 3.1 (Сложение)
1. $3 + \omega$:  
   По определению для предельного $\omega$: $3 + \omega = \sup_{n < \omega} (3 + n) = \omega$.  
   *Ответ*: $\omega$.
2. $\omega + 5 + \omega$:  
   $(\omega + 5) + \omega = \sup_{n < \omega} ((\omega + 5) + n) = \sup_{n < \omega} (\omega + (5 + n)) = \omega + \omega = \omega \cdot 2$.  
   *Ответ*: $\omega \cdot 2$.
3. $(\omega + 1) + \omega$:  
   По свойству ассоциативности: $\omega + (1 + \omega) = \omega + \omega = \omega \cdot 2$.  
   *Ответ*: $\omega \cdot 2$.
4. $\omega^2 + \omega + \omega^2$:  
   $(\omega^2 + \omega) + \omega^2 = \sup_{n < \omega} ((\omega^2 + \omega) + \omega \cdot n) = \omega^2 + \omega^2 = \omega^2 \cdot 2$. Младший член $\omega$ поглощается старшим $\omega^2$.  
   *Ответ*: $\omega^2 \cdot 2$.

#### Задание 3.2 (Умножение и степени)
1. $4 \cdot \omega = \sup_{n < \omega} (4 \cdot n) = \omega$. *Ответ*: $\omega$.
2. $\omega \cdot 3 = \omega + \omega + \omega$. Это канонический вид (три последовательные копии $\omega$). *Ответ*: $\omega \cdot 3$.
3. $(\omega + 1) \cdot 2 = (\omega + 1) + (\omega + 1) = \omega + (1 + \omega) + 1 = \omega + \omega + 1 = \omega \cdot 2 + 1$. *Ответ*: $\omega \cdot 2 + 1$.
4. $2 \cdot (\omega + 1) = 2 \cdot \omega + 2 \cdot 1 = \omega + 2$. *Ответ*: $\omega + 2$.
5. $3^\omega = \sup_{n < \omega} 3^n = \omega$. *Ответ*: $\omega$.
6. $\omega^2 \cdot \omega^3 = \omega^{2 + 3} = \omega^5$. *Ответ*: $\omega^5$.

### Решение к Блоку 4

#### Задание 4.1
- Докажем $\alpha \le \beta \implies \gamma + \alpha \le \gamma + \beta$ индукцией по $\beta$:
  - Если $\beta = \alpha$, утверждение тривиально: $\gamma + \alpha \le \gamma + \alpha$.
  - Если $\beta = \delta + 1$, то по индукционному предположению $\gamma + \alpha \le \gamma + \delta < (\gamma + \delta) + 1 = \gamma + \beta$.
  - Если $\beta$ предельный, то $\gamma + \beta = \sup_{\xi < \beta} (\gamma + \xi) \ge \gamma + \alpha$ (так как $\alpha < \beta \implies \alpha \le \xi$ для некоторого $\xi < \beta$).
- **Для правого слагаемого утверждение НЕВЕРНО!**  
  *Контрпример*: Возьмём $\alpha = 1, \beta = 2, \gamma = \omega$.  
  Очевидно, $1 < 2$.  
  Однако:
  $$1 + \omega = \omega \quad \text{и} \quad 2 + \omega = \omega$$
  То есть $1 + \omega = 2 + \omega$, строгое неравенство не сохраняется!  
  А если рассмотреть равенство: $1 < 2$, но $1 + \omega \not< 2 + \omega$.

#### Задание 4.2
Пусть $\alpha$ — ординал фон Неймана.
1. По определению ординала $\alpha$ транзитивно и вполне упорядочено отношением $\in$.
2. Для любого непустого подмножества $S \subseteq \alpha$ рассмотрим элемент $m \in S$, минимальный по отношению $\in$ (существование гарантируется аксиомой регулярности/фундирования: $m \cap S = \varnothing$).
3. Так как $m \cap S = \varnothing$, никакой элемент из $S$ не принадлежит $m$. А для ординалов любые два элемента сравнимы ($x \in m \lor x = m \lor m \in x$). Так как $x \in m$ невозможно при $x \in S$, остаётся $m = x \lor m \in x$, то есть $m \le x$ для всех $x \in S$.
4. Следовательно, $m$ — наименьший элемент $S$. Значит, $\alpha$ вполне упорядочено.
