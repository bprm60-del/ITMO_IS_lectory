Предикаты - утверждения с переменной. Кванторы - вещи, которые превращают их в высказывания

Определение: Предикат P(x) - утверждение, истинность которого зависит от значения x
Определение: Предметная область - множество всех допустимых значений x
(предикат - шаблон)
Запись: для всех - $\forall$ 
(по сути большая конъюнкция всех P(x))
Запись: существует - $\exists$ 

Переменная под знаком квантора - связанная. вне - свободная
Область действия квантора - формула, к которой он применяется

Открытая формула - предикат!!!

Теорема кванторов
Доказательство: 
	$\not \forall x. P(x)$  , истинно ровно когда не все x дают P(x), то есть существует x с ложным P(x)
	 $\not \exists P(x)$ значит, что ни один x не даёт P(x), то есть $\forall x. \not P(x)$ 
	 Отрицание проноситься сквозь квантор
Порядок кванторов меняет смысл утверждения
Читаются они в порядке.

$\forall x \in A. P(x) - это \forall X. (x \in A) -> P(x)$ 
$\exists \in A. P(x) - это\exists x. (x \in A) \land P(x)$ 
В пустой области "для всеx" истинно: посылка x $\in$ $\not0$ - верно всегда
