## Подробные решения и разборы заданий

### Решение к Заданию 1.1

1. $\lim_{n \to \infty} x_n = +\infty \iff \forall M > 0 \; \exists N \in \mathbb{N} : \forall n > N \implies x_n > M$.
2. $\lim_{n \to \infty} x_n = -\infty \iff \forall M > 0 \; \exists N \in \mathbb{N} : \forall n > N \implies x_n < -M$.
3. $\lim_{n \to \infty} x_n = \infty \iff \forall M > 0 \; \exists N \in \mathbb{N} : \forall n > N \implies |x_n| > M$.
4. **Доказательство для $(-1)^n n$**:
   - Возьмем произвольное $M > 0$. Положим $N = \lceil M \rceil$.  
     Тогда для любого $n > N$: $|x_n| = |(-1)^n n| = n > N \ge M$.  
     Следовательно, $\lim_{n \to \infty} x_n = \infty$.
   - При этом для нечетных $n = 2k + 1$ значения $x_n = -(2k + 1) < 0$, поэтому условие $x_n > M$ не может выполняться для всех $n > N$. Значит, предела $+\infty$ нет.  
   - Аналогично для четных $n = 2k$ значения $x_n = 2k > 0$, поэтому предела $-\infty$ также нет.

### Решение к Заданию 2.1

1. Рассмотрим отношение:
   $$\frac{\frac{n^2 + 5n}{2n^3 - 1}}{\frac{1}{\sqrt{n}}} = \frac{\sqrt{n}(n^2 + 5n)}{2n^3 - 1} = \frac{n^{2.5} + 5n^{1.5}}{2n^3 - 1} = \frac{\frac{1}{\sqrt{n}} + \frac{5}{n^{1.5}}}{2 - \frac{1}{n^3}} \xrightarrow{n \to \infty} \frac{0 + 0}{2 - 0} = 0$$
   Так как предел отношения равен 0, то по определению $\frac{n^2 + 5n}{2n^3 - 1} = o(1/\sqrt{n})$. $\blacksquare$

2. Домножим и разделим на сопряженное выражение:
   $$\sqrt{n^2 + 3n} - n = \frac{(\sqrt{n^2 + 3n} - n)(\sqrt{n^2 + 3n} + n)}{\sqrt{n^2 + 3n} + n} = \frac{n^2 + 3n - n^2}{\sqrt{n^2 + 3n} + n} = \frac{3n}{n\left(\sqrt{1 + 3/n} + 1\right)} = \frac{3}{\sqrt{1 + 3/n} + 1}$$
   Предел равен $\lim_{n \to \infty} \frac{3}{1 + 1} = \frac{3}{2}$.  
   Так как последовательность сходится к конечному числу, она ограничена, то есть является $O(1)$. $\blacksquare$

3. Преобразуем логарифм:
   $$\ln(n^3 + 4n) = \ln\left(n^3\left(1 + \frac{4}{n^2}\right)\right) = \ln(n^3) + \ln\left(1 + \frac{4}{n^2}\right) = 3\ln n + o(1)$$
   Отношение к $\ln n$:
   $$\frac{\ln(n^3 + 4n)}{\ln n} = \frac{3\ln n + o(1)}{\ln n} = 3 + o(1) \xrightarrow{n \to \infty} 3$$
   Так как отношение ограничено константой 3, то $\ln(n^3 + 4n) = O(\ln n)$ (более того, $\Theta(\ln n)$). $\blacksquare$

4. Поделим сумму на $n!$:
   $$\frac{n! + 2^n + n^{100}}{n!} = 1 + \frac{2^n}{n!} + \frac{n^{100}}{n!}$$
   По шкале роста экспонента и степень растут существенно медленнее факториала: $\lim \frac{2^n}{n!} = 0$ и $\lim \frac{n^{100}}{n!} = 0$.  
   Следовательно:
   $$\lim_{n \to \infty} \frac{n! + 2^n + n^{100}}{n!} = 1 + 0 + 0 = 1 \iff n! + 2^n + n^{100} \sim n! \quad \blacksquare$$

### Решение к Заданию 3.1

Если $r = 0$, то $0^n = 0 \to 0$ тривиально.  
Пусть $0 < |r| < 1$. Тогда $\frac{1}{|r|} > 1$. Обозначим $h = \frac{1}{|r|} - 1 > 0$.  
Тогда $\frac{1}{|r|} = 1 + h$.  
По **неравенству Бернулли**:
$$\frac{1}{|r|^n} = (1 + h)^n \ge 1 + nh > nh$$
Отсюда:
$$|r^n - 0| = |r|^n < \frac{1}{nh}$$
Зафиксируем $\varepsilon > 0$. Нам нужно, чтобы $\frac{1}{nh} < \varepsilon \iff n > \frac{1}{\varepsilon h}$.  
Положим $N(\varepsilon) = \left\lceil \frac{1}{\varepsilon h} \right\rceil$.  
Тогда для всех $n > N(\varepsilon)$ выполнено $|r^n| < \varepsilon$.  
Следовательно, $\lim_{n \to \infty} r^n = 0$. $\blacksquare$

### Решение к Заданию 3.2

1. $x_n = \frac{100^n}{n!}$.  
   $$\frac{x_{n+1}}{x_n} = \frac{100^{n+1}}{(n+1)!} \cdot \frac{n!}{100^n} = \frac{100}{n+1} \xrightarrow{n \to \infty} 0 = q < 1$$  
   По признаку Даламбера предел равен $0$.
2. $x_n = \frac{n^k}{2^n}$.  
   $$\frac{x_{n+1}}{x_n} = \frac{(n+1)^k}{2^{n+1}} \cdot \frac{2^n}{n^k} = \frac{1}{2}\left(1 + \frac{1}{n}\right)^k \xrightarrow{n \to \infty} \frac{1}{2} = q < 1$$  
   По признаку Даламбера предел равен $0$.
3. $x_n = \frac{(2n)!}{n^{2n}}$.  
   $$\frac{x_{n+1}}{x_n} = \frac{(2n+2)!}{(n+1)^{2n+2}} \cdot \frac{n^{2n}}{(2n)!} = \frac{(2n+1)(2n+2)}{(n+1)^2} \cdot \left(\frac{n}{n+1}\right)^{2n} = \frac{2(2n+1)}{n+1} \cdot \frac{1}{\left(1 + \frac{1}{n}\right)^{2n}}$$  
   Пределы множителей: $\lim \frac{2(2n+1)}{n+1} = 4$, а $\lim \left(1 + \frac{1}{n}\right)^{2n} = e^2$.  
   Получаем:
   $$q = \lim_{n \to \infty} \frac{x_{n+1}}{x_n} = \frac{4}{e^2} \approx \frac{4}{7.389} \approx 0.541 < 1$$  
   Так как $q < 1$, по признаку Даламбера $\lim_{n \to \infty} \frac{(2n)!}{n^{2n}} = 0$.
