Множества равномощны когда существует биекция X -> Y
Если X и Y равномощны (X знак равномощности Y)

Мощность - название класса равномощного к которому оно принадлежит
Свойства отношения равномощности:
1) Рефлексивность
2) Симметричность
3) Транзитивность

Множество называется счётным, если  равномощно N
|N| = a

Пример:
Парадокс Дедекинда N равномощно 2N

Определение Кантора-Бернштейна:
Существует инъективное из A в B <=> |A| <= |B|
Теорема:
	|A| <= |B| и |B| >= |A|
Свойства подмножеств:
Любое подмножества счётного множества - либо счётное, либо конечно (НБЧС - не более чем счётное)
Любое бесконечное подмножество счётного - счётного
Любое удаление конечного подмножества из счётного множества не меняет его мощность

Теорема о счётности объединения
Любое объединение счётного множества со счётным - счётного
Доказательство:
	Пусть A - счётно и B - счётно.
	Тогда будем объединять наши множества по порядку:
	C = {A1, B1, A2, B2, ... An, Bn, ... }
	Диагональ 1: a1,1 
	Диагональ 2: a2,1 ; a1,2
	.............
