## Подробные решения и разборы заданий

### Решение к Заданию 1.1

1. **$E_1 = (0, 1] \cup \{2\}$**:
   - Внутренность: $\operatorname{int}(E_1) = (0, 1)$.
   - Предельные точки: $E_1' = [0, 1]$ (точка $2$ не предельная, а $0$ и $1$ предельные).
   - Изолированные точки: $\{2\}$ (в окрестности $(2 - 0.5, 2 + 0.5)$ других точек $E_1$ нет).
   - Граница: $\partial E_1 = \{0, 1, 2\}$.
   - Замыкание: $\overline{E_1} = [0, 1] \cup \{2\}$.
   - Тип: **ни открыто, ни замкнуто** (содержит точку $1$, но не открыто; не содержит предельную точку $0$, но содержит изолированную $2$).

2. **$E_2 = \{1/n \mid n \in \mathbb{N}\}$**:
   - Внутренность: $\operatorname{int}(E_2) = \emptyset$ (ни один интервал не помещается в счетное дискретное множество).
   - Предельные точки: $E_2' = \{0\}$ (так как $\lim_{n \to \infty} \frac{1}{n} = 0$, любая проколотая окрестность нуля содержит бесконечно много точек $1/n$).
   - Изолированные точки: все точки множества $E_2$ (для $1/n$ расстояние до ближайшей точки $1/(n+1)$ равно $\frac{1}{n(n+1)} > 0$).
   - Граница: $\partial E_2 = E_2 \cup \{0\}$.
   - Замыкание: $\overline{E_2} = E_2 \cup \{0\}$.
   - Тип: **ни открыто, ни замкнуто** (не содержит своей единственной предельной точки $0$).

3. **$E_3 = \mathbb{Q} \cap [0, 1]$**:
   - Внутренность: $\operatorname{int}(E_3) = \emptyset$ (в любом интервале есть иррациональные числа).
   - Предельные точки: $E_3' = [0, 1]$ (в силу плотности рациональных чисел).
   - Изолированные точки: $\emptyset$.
   - Граница: $\partial E_3 = [0, 1]$.
   - Замыкание: $\overline{E_3} = [0, 1]$.
   - Тип: **ни открыто, ни замкнуто**.

### Строгое доказательство Задания 2.1

1. **Интервал $(a, b)$ открыт**:  
   Возьмем произвольную точку $x_0 \in (a, b)$. Это значит, что $a < x_0 < b$.  
   Положим $\varepsilon = \min(x_0 - a, b - x_0) > 0$.  
   Тогда для любой точки $x \in U_\varepsilon(x_0) = (x_0 - \varepsilon, x_0 + \varepsilon)$ имеем:
   $$x > x_0 - \varepsilon \ge x_0 - (x_0 - a) = a$$
   $$x < x_0 + \varepsilon \le x_0 + (b - x_0) = b$$
   Следовательно, $U_\varepsilon(x_0) \subseteq (a, b)$.  
   Точка $x_0$ — внутренняя. Так как точка выбрана произвольно, интервал открыт. $\blacksquare$

2. **Отрезок $[a, b]$ замкнут**:  
   По теореме о двойственности достаточно доказать, что его дополнение $\mathbb{R} \setminus [a, b] = (-\infty, a) \cup (b, +\infty)$ открыто.  
   - Луч $(-\infty, a)$ открыт: для любой $x_0 < a$ окрестность радиуса $\varepsilon = a - x_0 > 0$ целиком лежит в $(-\infty, a)$.  
   - Луч $(b, +\infty)$ аналогично открыт.  
   Объединение двух открытых лучей открыто по теореме об алгебре открытых множеств.  
   Следовательно, дополнение открыто $\implies [a, b]$ замкнут. $\blacksquare$

### Решение к Заданию 3.1

1. **Для $[0, 1)$**:  
   Рассмотрим семейство открытых интервалов:
   $$G_n = \left(-1, \; 1 - \frac{1}{n}\right) \quad \text{для } n \ge 2$$
   - Каждое $G_n$ открыто.  
   - Объединение: $\bigcup_{n=2}^\infty G_n = (-1, 1) \supset [0, 1)$, то есть семейство является открытым покрытием $[0, 1)$.  
   - Возьмем любое конечное подсемейство $\{G_{n_1}, \dots, G_{n_k}\}$.  
     Пусть $N = \max\{n_1, \dots, n_k\}$. Тогда их объединение равно интервалу $\left(-1, 1 - \frac{1}{N}\right)$.  
     Однако точка $x = 1 - \frac{1}{2N} \in [0, 1)$ не попадает в это объединение, так как $1 - \frac{1}{2N} > 1 - \frac{1}{N}$.  
   Конечного подпокрытия не существует. Множество $[0, 1)$ **не компактно**.

2. **Для $\mathbb{N}$**:  
   Рассмотрим окрестности каждой точки:
   $$G_n = \left(n - \frac{1}{3}, \; n + \frac{1}{3}\right) \quad \text{для } n \in \mathbb{N}$$
   Интервалы попарно не пересекаются, и каждый содержит ровно одну натуральную точку $n$.  
   Семейство $\{G_n\}_{n \in \mathbb{N}}$ покрывает $\mathbb{N}$.  
   Любое конечное подсемейство содержит лишь конечное число интервалов, а значит, покрывает лишь конечное подмножество $\mathbb{N}$.  
   Выделить конечное подпокрытие невозможно. Множество $\mathbb{N}$ **не компактно**.

### Строгое доказательство Задания 3.2

Предположим от противного, что $\bigcap_{n=1}^\infty K_n = \emptyset$.  
Тогда по закону де Моргана:
$$\mathbb{R} = \mathbb{R} \setminus \left(\bigcap_{n=1}^\infty K_n\right) = \bigcup_{n=1}^\infty (\mathbb{R} \setminus K_n)$$
В частности, исходный компакт $K_1 \subseteq \mathbb{R}$ покрывается семейством открытых множеств $G_n = \mathbb{R} \setminus K_n$:
$$K_1 \subseteq \bigcup_{n=1}^\infty (\mathbb{R} \setminus K_n)$$
Так как $K_1$ компактен, по определению компактности существует конечное подпокрытие:
$$K_1 \subseteq \bigcup_{i=1}^m (\mathbb{R} \setminus K_{n_i})$$
Пусть $N = \max\{n_1, \dots, n_m\}$. Так как множества $K_n$ вложены ($K_1 \supset K_2 \supset \dots \supset K_N$), то их дополнения также вложены в обратную сторону:
$$\mathbb{R} \setminus K_1 \subset \mathbb{R} \setminus K_2 \subset \dots \subset \mathbb{R} \setminus K_N$$
Следовательно, объединение конечного числа дополнений равно наибольшему дополнению:
$$\bigcup_{i=1}^m (\mathbb{R} \setminus K_{n_i}) = \mathbb{R} \setminus K_N$$
Тогда получаем:
$$K_1 \subseteq \mathbb{R} \setminus K_N \iff K_1 \cap K_N = \emptyset$$
Но по условию вложенности $K_N \subseteq K_1$, откуда $K_1 \cap K_N = K_N \ne \emptyset$.  
Полученное противоречие ($K_N = \emptyset$) доказывает, что $\bigcap_{n=1}^\infty K_n \ne \emptyset$. $\blacksquare$
