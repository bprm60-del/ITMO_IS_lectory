Точка x_0 предельная точка множества (т.е. любая проколотая её окрестность содержит хоть одну точку)

Опр:
	Число a называется пределом функции f(x) при x -> x_0 если
	Для любого e > 0; $\exists \gamma_e : 0 < |x-x_0| < \gamma_e => |f(x)-a| < e$  
	(По Коши)

На языке окрестностей:
	lim(f(x)) = a <=> f(x) находится в эпсилон окрестности точки a

Определение по Гейне:
	lim f(x) = a <=> для любой последовательности {x_n} такой что $x_n \in E$ and $\forall x_n != x_0$ и $lim x+n = x_0 => lim f(x_n) = a$
