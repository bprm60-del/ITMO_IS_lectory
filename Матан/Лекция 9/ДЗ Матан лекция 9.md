### Ответы на Блок 1 (Контрольные вопросы)

#### Ответ на Вопрос 1.1
- **Окрестность $+\infty$**: $U_M(+\infty) = \{x \in \mathbb{R} \mid x > M\} = (M, +\infty)$. Точки обязаны быть положительными и сколь угодно большими.
- **Окрестность $-\infty$**: $U_M(-\infty) = \{x \in \mathbb{R} \mid x < -M\} = (-\infty, -M)$. Точки обязаны быть отрицательными с модулем, превышающим $M$.
- **Окрестность $\infty$ (без знака)**: $\dot{U}_M(\infty) = \{x \in \mathbb{R} \mid |x| > M\} = (-\infty, -M) \cup (M, +\infty)$. Знак аргумента роли не играет, учитывается лишь его удалённость от начала координат.

#### Ответ на Вопрос 1.2
Теорема утверждает: если $\lim_{x \to x_0} g(x) = y_0$, $\lim_{y \to y_0} f(y) = a$ и в некоторой проколотой окрестности $\dot{U}(x_0)$ выполнено $g(x) \ne y_0$ (условие невозвращения), то $\lim_{x \to x_0} f(g(x)) = a$.  
В определении предела по Коши окрестность целевой точки $y_0$ проколота: $\dot{U}_\varepsilon(y_0)$, то есть значение в самой точке $f(y_0)$ не рассматривается. Если же $g(x)$ попадает ровно в $y_0$, аргумент внешней функции оказывается в точке прокола, где функция $f$ может иметь разрыв.  
**Контрпример**: $g(x) \equiv 0 \implies \lim_{x \to 0} g(x) = 0$. Пусть $f(y) = 1$ при $y \ne 0$ и $f(0) = 0 \implies \lim_{y \to 0} f(y) = 1$. Но $f(g(x)) = f(0) = 0 \implies \lim_{x \to 0} f(g(x)) = 0 \ne 1$.

#### Ответ на Вопрос 1.3
1. В единичном круге $R = 1$ для $x \in (0, \pi/2)$ треугольник $\triangle OMA$ с площадью $\frac{1}{2} \sin x$ строго содержится внутри сектора $OMA$ с площадью $\frac{1}{2} x$, а сектор целиком содержится в треугольнике $\triangle OTA$ с высотой $\operatorname{tg} x$ и площадью $\frac{1}{2} \operatorname{tg} x$. Отсюда $\sin x < x < \operatorname{tg} x \implies \cos x < \frac{\sin x}{x} < 1$.
2. Функции $\cos x$ и $\frac{\sin x}{x}$ являются чётными: $\cos(-x) = \cos x$ и $\frac{\sin(-x)}{-x} = \frac{\sin x}{x}$. Поэтому симметричное неравенство сохраняется для всех $x \in (-\pi/2, 0)$. По теореме о зажатой функции при $x \to 0$ предел равен $1$.

#### Ответ на Вопрос 1.4
Используем тригонометрическое тождество $1 - \cos x = 2 \sin^2(x/2)$:
$$\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \lim_{x \to 0} \frac{2 \sin^2(x/2)}{x^2} = 2 \lim_{x \to 0} \left(\frac{\sin(x/2)}{x/2}\right)^2 \cdot \frac{1}{4} = 2 \cdot 1^2 \cdot \frac{1}{4} = \frac{1}{2}$$
Коэффициент $1/2$ возникает из возведения в квадрат коэффициента аргумента половинного угла: $(1/2)^2 = 1/4$ при умножении на $2$.

#### Ответ на Вопрос 1.5
Замена $x = -(t + 1)$. При $x \to -\infty$ величина $t \to +\infty$.
$$1 + \frac{1}{x} = 1 - \frac{1}{t+1} = \frac{t}{t+1} = \frac{1}{1 + \frac{1}{t}}$$
Возводя в степень $x = -(t+1)$:
$$\left(1 + \frac{1}{x}\right)^x = \left(\frac{1}{1 + 1/t}\right)^{-(t+1)} = \left(1 + \frac{1}{t}\right)^{t+1} = \left(1 + \frac{1}{t}\right)^t \cdot \left(1 + \frac{1}{t}\right) \to e \cdot 1 = e$$

#### Ответ на Вопрос 1.6
Если $\alpha(x) \sim \alpha_1(x)$ и $\beta(x) \sim \beta_1(x)$, то $\lim \frac{\alpha(x) \beta(x)}{\gamma(x)} = \lim \frac{\alpha_1(x) \beta_1(x)}{\gamma(x)}$, так как $\frac{\alpha(x)}{\alpha_1(x)} \to 1$.  
Но для разности: $\alpha(x) - \beta(x) \ne \alpha_1(x) - \beta_1(x)$. Если $\alpha_1(x) = \beta_1(x)$ (главные части одинаковы), их разность равна 0, в то время как истинная разность $\alpha(x) - \beta(x)$ определяется следующими членами асимптотического разложения (например, $\sin x - x \sim -\frac{x^3}{6} \ne 0$).

### Решение к Блоку 2

#### Задание 2.1
1. **Предел $\lim_{x \to 2} \frac{x^3 - 3x^2 + 4}{x^3 - 4x^2 + 4x}$**:
   - При $x = 2$: числитель $8 - 12 + 4 = 0$, знаменатель $8 - 16 + 8 = 0$ (неопределённость $[0/0]$).
   - Раскладываем на множители:
     - Числитель: корень $x = 2$. Делением угла получаем $x^3 - 3x^2 + 4 = (x - 2)(x^2 - x - 2) = (x - 2)^2 (x + 1)$.
     - Знаменатель: $x(x^2 - 4x + 4) = x(x - 2)^2$.
   - Сокращаем на $(x - 2)^2 \ne 0$:
     $$\lim_{x \to 2} \frac{(x - 2)^2 (x + 1)}{x(x - 2)^2} = \lim_{x \to 2} \frac{x + 1}{x} = \frac{3}{2}$$
   *Ответ*: $\frac{3}{2}$.

2. **Предел $\lim_{x \to 1} \frac{x^m - 1}{x^n - 1}$**:
   - Формула разности степеней: $x^k - 1 = (x - 1)(x^{k-1} + x^{k-2} + \dots + 1)$.
   - Сокращаем на $(x - 1)$:
     $$\lim_{x \to 1} \frac{(x - 1)(x^{m-1} + \dots + 1)}{(x - 1)(x^{n-1} + \dots + 1)} = \frac{\underbrace{1 + 1 + \dots + 1}_{m \text{ слагаемых}}}{\underbrace{1 + 1 + \dots + 1}_{n \text{ слагаемых}}} = \frac{m}{n}$$
   *Ответ*: $\frac{m}{n}$.

#### Задание 2.2
1. **Предел $\lim_{x \to 0} \frac{\sqrt{1 + x + x^2} - 1}{x}$**:
   - Умножаем на сопряжённое $\sqrt{1 + x + x^2} + 1$:
     $$\lim_{x \to 0} \frac{(1 + x + x^2) - 1}{x (\sqrt{1 + x + x^2} + 1)} = \lim_{x \to 0} \frac{x(1 + x)}{x (\sqrt{1 + x + x^2} + 1)} = \lim_{x \to 0} \frac{1 + x}{\sqrt{1 + x + x^2} + 1} = \frac{1}{1 + 1} = \frac{1}{2}$$
   *Ответ*: $\frac{1}{2}$.

2. **Предел $\lim_{x \to 7} \frac{\sqrt{x + 2} - 3}{\sqrt{x - 3} - 2}$**:
   - Умножаем одновременно на сопряжённые числителя и знаменателя:
     $$\frac{(\sqrt{x+2} - 3)(\sqrt{x+2} + 3)(\sqrt{x-3} + 2)}{(\sqrt{x-3} - 2)(\sqrt{x-3} + 2)(\sqrt{x+2} + 3)} = \frac{(x + 2 - 9)(\sqrt{x-3} + 2)}{(x - 3 - 4)(\sqrt{x+2} + 3)} = \frac{(x - 7)(\sqrt{x-3} + 2)}{(x - 7)(\sqrt{x+2} + 3)}$$
   - Сокращаем на $x - 7$:
     $$\lim_{x \to 7} \frac{\sqrt{x-3} + 2}{\sqrt{x+2} + 3} = \frac{\sqrt{4} + 2}{\sqrt{9} + 3} = \frac{2 + 2}{3 + 3} = \frac{4}{6} = \frac{2}{3}$$
   *Ответ*: $\frac{2}{3}$.

3. **Предел $\lim_{x \to 0} \frac{\sqrt[3]{1 + 3x} - \sqrt{1 - 2x}}{x + x^2}$**:
   - Прибавим и вычтем $1$ в числителе:
     $$\frac{(\sqrt[3]{1 + 3x} - 1) - (\sqrt{1 - 2x} - 1)}{x(1 + x)}$$
   - По формуле $(1 + u)^\alpha - 1 \sim \alpha u$:
     - $\sqrt[3]{1 + 3x} - 1 = (1 + 3x)^{1/3} - 1 \sim \frac{1}{3} (3x) = x$.
     - $\sqrt{1 - 2x} - 1 = (1 - 2x)^{1/2} - 1 \sim \frac{1}{2} (-2x) = -x$.
   - Числитель: $x - (-x) = 2x$. Знаменатель: $x(1 + x) \sim x$.
   - Предел: $\lim_{x \to 0} \frac{2x}{x} = 2$.
   *Ответ*: $2$.

#### Задание 2.3
1. **Предел $\lim_{x \to +\infty} \frac{3x^3 - 2x + 7}{5x^3 + 4x^2 - 1}$**:
   - Выносим старшую степень $x^3$:
     $$\lim_{x \to +\infty} \frac{x^3 (3 - 2/x^2 + 7/x^3)}{x^3 (5 + 4/x - 1/x^3)} = \frac{3 - 0 + 0}{5 + 0 - 0} = \frac{3}{5}$$
   *Ответ*: $\frac{3}{5}$.

2. **Предел $\lim_{x \to +\infty} \left(\sqrt{x^2 + 5x} - \sqrt{x^2 - 3x}\right)$**:
   - Умножаем и делим на сумму корней:
     $$\frac{(x^2 + 5x) - (x^2 - 3x)}{\sqrt{x^2 + 5x} + \sqrt{x^2 - 3x}} = \frac{8x}{x\sqrt{1 + 5/x} + x\sqrt{1 - 3/x}} = \frac{8}{\sqrt{1 + 5/x} + \sqrt{1 - 3/x}}$$
   - При $x \to +\infty$: $\frac{8}{1 + 1} = 4$.
   *Ответ*: $4$.

3. **Предел $\lim_{x \to -\infty} \left(\sqrt{x^2 + 2x} + x\right)$**:
   - Заметим, что при $x \to -\infty$ имеем $\sqrt{x^2} = |x| = -x$, поэтому выражение представляет собой неопределённость $[\infty - \infty]$.
   - Домножаем на сопряжённое $\sqrt{x^2 + 2x} - x$:
     $$\frac{(x^2 + 2x) - x^2}{\sqrt{x^2 + 2x} - x} = \frac{2x}{\sqrt{x^2(1 + 2/x)} - x} = \frac{2x}{|x|\sqrt{1 + 2/x} - x}$$
   - Так как $x < 0$, то $|x| = -x$:
     $$\frac{2x}{-x\sqrt{1 + 2/x} - x} = \frac{2x}{-x(\sqrt{1 + 2/x} + 1)} = \frac{2}{-(\sqrt{1 + 2/x} + 1)} \xrightarrow{x \to -\infty} \frac{2}{-(1 + 1)} = -1$$
   *Ответ*: $-1$.

#### Задание 3.2 (Анализ ошибки)
Функция $g(x) = x \sin(1/x)$ принимает значение $0$ в бесконечном числе точек в любой сколь угодно малой окрестности нуля ($x_k = \frac{1}{\pi k} \to 0$). Поэтому **условие невозвращения нарушено**: $g(x_k) = 0 = y_0$.  
Более того, внешняя функция $f(y)$ не является непрерывной в $y_0 = 0$ ($f(0) = 0$, но $\lim_{y \to 0} f(y) = 2$).  
Рассмотрим две последовательности, стремящиеся к $0$:
1. $x_n = \frac{1}{\pi n} \implies g(x_n) = 0 \implies f(g(x_n)) = f(0) = 0 \to 0$.
2. $x_n' = \frac{1}{\frac{\pi}{2} + 2\pi n} \implies g(x_n') = x_n' \cdot 1 \ne 0 \implies f(g(x_n')) = 2 \to 2$.  
Так как получены два разных частичных предела ($0$ и $2$), по критерию Гейне предел **не существует**.

### Решение к Блоку 4

#### Задание 4.1
1. $\displaystyle \lim_{x \to 0} \frac{\sin(7x)}{\sin(3x)} = \lim_{x \to 0} \frac{\frac{\sin(7x)}{7x} \cdot 7x}{\frac{\sin(3x)}{3x} \cdot 3x} = \frac{1 \cdot 7}{1 \cdot 3} = \frac{7}{3}$. *Ответ*: $\frac{7}{3}$.
2. $\displaystyle \lim_{x \to 0} \frac{\operatorname{tg}(2x)}{\arcsin(5x)} = \lim_{x \to 0} \frac{2x}{5x} = \frac{2}{5}$ (по эквивалентностям $\operatorname{tg} u \sim u$, $\arcsin u \sim u$). *Ответ*: $\frac{2}{5}$.
3. $\displaystyle \lim_{x \to 0} \frac{\operatorname{arctg}(3x)}{\operatorname{tg}(4x)} = \lim_{x \to 0} \frac{3x}{4x} = \frac{3}{4}$. *Ответ*: $\frac{3}{4}$.

#### Задание 4.2
1. $\displaystyle \lim_{x \to 0} \frac{1 - \cos(4x)}{x \sin(3x)} = \lim_{x \to 0} \frac{\frac{(4x)^2}{2}}{x \cdot 3x} = \lim_{x \to 0} \frac{8x^2}{3x^2} = \frac{8}{3}$. *Ответ*: $\frac{8}{3}$.
2. $\displaystyle \lim_{x \to 0} \frac{\cos(x) - \cos(3x)}{x^2} = \lim_{x \to 0} \frac{2 \sin(2x) \sin(x)}{x^2} = 2 \cdot 2 \cdot 1 = 4$. *Ответ*: $4$.
3. $\displaystyle \lim_{x \to 0} \frac{\operatorname{tg}(x) - \sin(x)}{x^3} = \lim_{x \to 0} \frac{\sin(x)\left(\frac{1}{\cos x} - 1\right)}{x^3} = \lim_{x \to 0} \frac{\sin(x)(1 - \cos x)}{x^3 \cos x} = \lim_{x \to 0} \left(\frac{\sin x}{x} \cdot \frac{1 - \cos x}{x^2} \cdot \frac{1}{\cos x}\right) = 1 \cdot \frac{1}{2} \cdot 1 = \frac{1}{2}$. *Ответ*: $\frac{1}{2}$.

#### Задание 4.3
1. $\displaystyle \lim_{x \to \pi} \frac{\sin(x)}{\pi - x}$: замена $t = \pi - x \implies x = \pi - t$. При $x \to \pi$ аргумент $t \to 0$.
   $$\sin(\pi - t) = \sin(t) \implies \lim_{t \to 0} \frac{\sin(t)}{t} = 1$$
   *Ответ*: $1$.
2. $\displaystyle \lim_{x \to \pi/4} \frac{\cos(x) - \sin(x)}{\cos(2x)}$:
   - Раскладываем знаменатель: $\cos(2x) = \cos^2(x) - \sin^2(x) = (\cos x - \sin x)(\cos x + \sin x)$.
   - Сокращаем на $(\cos x - \sin x) \ne 0$:
     $$\lim_{x \to \pi/4} \frac{1}{\cos x + \sin x} = \frac{1}{\frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2}} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$
   *Ответ*: $\frac{\sqrt{2}}{2}$.

### Решение к Блоку 5

#### Задание 5.1
1. $\displaystyle \lim_{x \to \infty} \left(1 - \frac{2}{x}\right)^{3x} = \lim_{x \to \infty} \left[\left(1 + \left(-\frac{2}{x}\right)\right)^{-\frac{x}{2}}\right]^{-\frac{2}{x} \cdot 3x} = e^{-6}$. *Ответ*: $e^{-6}$.
2. $\displaystyle \lim_{x \to \infty} \left(\frac{x + 3}{x - 1}\right)^{2x + 1}$:
   - Основание: $\frac{x + 3}{x - 1} = 1 + \frac{4}{x - 1}$.
   - Показатель: $\alpha(x) \cdot (2x + 1) = \frac{4(2x + 1)}{x - 1} \to 8$ при $x \to \infty$.
   - Предел: $e^8$. *Ответ*: $e^8$.
3. $\displaystyle \lim_{x \to 0} \left(1 + \operatorname{tg}^2(\sqrt{x})\right)^{\frac{1}{2x}}$:
   - Так как $\operatorname{tg}(\sqrt{x}) \sim \sqrt{x}$, то $\alpha(x) = \operatorname{tg}^2(\sqrt{x}) \sim x$.
   - Предел показателя: $\lim_{x \to 0} \left(\alpha(x) \cdot \frac{1}{2x}\right) = \lim_{x \to 0} \frac{x}{2x} = \frac{1}{2}$.
   - Предел равен $e^{1/2} = \sqrt{e}$. *Ответ*: $\sqrt{e}$.
4. $\displaystyle \lim_{x \to 0} (\cos x)^{1/x^2}$:
   - Представим основание: $\cos x = 1 + (\cos x - 1) = 1 - (1 - \cos x)$.
   - Величина $\alpha(x) = \cos x - 1 \sim -\frac{x^2}{2}$.
   - Предел показателя: $\lim_{x \to 0} \left(\alpha(x) \cdot \frac{1}{x^2}\right) = \lim_{x \to 0} \frac{-x^2 / 2}{x^2} = -\frac{1}{2}$.
   - Предел равен $e^{-1/2} = \frac{1}{\sqrt{e}}$. *Ответ*: $\frac{1}{\sqrt{e}}$.

### Решение к Блоку 6

#### Задание 6.1
1. **Предел $\lim_{x \to 0} \frac{\ln(1 + \sin(3x))}{e^{\operatorname{tg}(2x)} - 1}$**:
   - При $x \to 0$: $\sin(3x) \sim 3x \implies \ln(1 + \sin(3x)) \sim \sin(3x) \sim 3x$.
   - $\operatorname{tg}(2x) \sim 2x \implies e^{\operatorname{tg}(2x)} - 1 \sim \operatorname{tg}(2x) \sim 2x$.
   - Предел: $\lim_{x \to 0} \frac{3x}{2x} = \frac{3}{2}$.
   *Ответ*: $\frac{3}{2}$.

2. **Предел $\lim_{x \to 0} \frac{\sqrt{1 + 4x} - \cos(2x)}{x^2 + \arcsin(2x)}$**:
   - Числитель: распишем относительно $1$:
     $$\sqrt{1 + 4x} - \cos(2x) = (\sqrt{1 + 4x} - 1) + (1 - \cos(2x)) \sim \frac{1}{2}(4x) + \frac{(2x)^2}{2} = 2x + 2x^2 \sim 2x$$
   - Знаменатель: $x^2 + \arcsin(2x) \sim 0 + 2x = 2x$.
   - Предел: $\lim_{x \to 0} \frac{2x}{2x} = 1$.
   *Ответ*: $1$.

3. **Предел $\lim_{x \to 0} \frac{e^{x^2} - \cos(2x)}{\sin^2(x)}$**:
   - Добавим и вычтем единицу в числителе:
     $$e^{x^2} - \cos(2x) = (e^{x^2} - 1) + (1 - \cos(2x))$$
   - По эквивалентностям:
     - $e^{x^2} - 1 \sim x^2$.
     - $1 - \cos(2x) \sim \frac{(2x)^2}{2} = 2x^2$.
     - Числитель: $x^2 + 2x^2 = 3x^2$.
   - Знаменатель: $\sin^2(x) \sim x^2$.
   - Предел: $\lim_{x \to 0} \frac{3x^2}{x^2} = 3$.
   *Ответ*: $3$.
