## ЧАСТЬ III. Полные пошаговые решения и ответы

### Ответы на контрольные вопросы

#### Вопрос 1 (Дифференцируемость vs Производная)
Для функций одной переменной $\mathbb{R} \to \mathbb{R}$ понятия дифференцируемости и существования конечной производной **полностью эквивалентны** (Теорема 1). Однако для функций нескольких переменных $\mathbb{R}^n \to \mathbb{R}$ ($n \ge 2$) существование всех частных производных $\frac{\partial f}{\partial x_i}$ **не гарантирует** дифференцируемости функции и даже не гарантирует её непрерывности! Для многомерного анализа дифференцируемость — это строгая аппроксимация линейным оператором (дифференциалом Фреше).

#### Вопрос 2 (Геометрический смысл разности $\Delta f - df$)
* $df = f'(x_0) \Delta x$ — приращение ординаты **касательной прямой**.
* $\Delta f = f(x_0 + \Delta x) - f(x_0)$ — приращение ординаты **самой кривой**.
* Разность $\Delta f - df = o(\Delta x)$ равна вертикальному расстоянию между точкой на графике функции и точкой на касательной при одном и том же значении аргумента $x_0 + \Delta x$. При $\Delta x \to 0$ это расстояние стремится к нулю быстрее, чем сам шаг $\Delta x$.

#### Вопрос 3 (Непрерывность и производная)
* Если $f$ дифференцируема, то $\Delta f = f'(x_0) \Delta x + o(\Delta x) \implies \lim_{\Delta x \to 0} \Delta f = 0 \implies f$ непрерывна.
* Функция $f(x) = x \sin(1/x)$ при $x \ne 0$, $f(0) = 0$ непрерывна в нуле, так как $|x \sin(1/x)| \le |x| \to 0$. Однако отношение приращений равно $\frac{\Delta f}{\Delta x} = \sin(1/\Delta x)$, предел которого при $\Delta x \to 0$ не существует даже в виде одностороннего предела (осцилляция между $-1$ и $1$).

#### Вопрос 4 (Сложная функция и $\Delta u = 0$)
Если делить «в лоб» $\frac{\Delta y}{\Delta x} = \frac{\Delta y}{\Delta u} \cdot \frac{\Delta u}{\Delta x}$, то при $\Delta u = 0$ возникает деление на ноль (например, если $g(x) = \text{const}$). Строгое доказательство (Теорема 4) обходит это рассмотрением вспомогательной функции $\alpha(\Delta u) = \frac{\Delta y}{\Delta u} - f'(u_0)$ при $\Delta u \ne 0$ и $\alpha(0) = 0$. Тогда тождество $\Delta y = f'(u_0) \Delta u + \alpha(\Delta u) \Delta u$ верно тождественно **при любых** $\Delta u$, включая $\Delta u = 0$, что устраняет проблему деления на ноль.

#### Вопрос 5 (Инвариантность формы первого дифференциала)
Инвариантность формы первого дифференциала означает, что выражение $df = f'(u) du$ имеет один и тот же вид независимо от того, является ли $u$ независимой переменной или функцией.  
Для второго дифференциала $d^2 f$ **инвариантность нарушается**:
* Если $x$ независима, то $d^2 x = 0$, и $d^2 f = f''(x) dx^2$.
* Если $u = u(x)$, то $d^2 f = d(f'(u) du) = f''(u) du^2 + f'(u) d^2 u$. Появляется дополнительное слагаемое $f'(u) d^2 u$!

### Решения заданий на самопрорешивание

#### Решение Задания 1 (Производные по определению)
1. $f(x) = \frac{1}{x^2}$:
   $$\Delta f = \frac{1}{(x + \Delta x)^2} - \frac{1}{x^2} = \frac{x^2 - (x^2 + 2x \Delta x + (\Delta x)^2)}{x^2 (x + \Delta x)^2} = \frac{-2x \Delta x - (\Delta x)^2}{x^2 (x + \Delta x)^2}$$
   $$\lim_{\Delta x \to 0} \frac{\Delta f}{\Delta x} = \lim_{\Delta x \to 0} \frac{-2x - \Delta x}{x^2 (x + \Delta x)^2} = \frac{-2x}{x^4} = -\frac{2}{x^3}$$
2. $f(x) = \sqrt{2x + 1}$:
   $$\Delta f = \sqrt{2(x + \Delta x) + 1} - \sqrt{2x + 1} = \frac{(2x + 2\Delta x + 1) - (2x + 1)}{\sqrt{2(x + \Delta x) + 1} + \sqrt{2x + 1}} = \frac{2\Delta x}{\sqrt{2x + 2\Delta x + 1} + \sqrt{2x + 1}}$$
   $$\lim_{\Delta x \to 0} \frac{\Delta f}{\Delta x} = \lim_{\Delta x \to 0} \frac{2}{\sqrt{2x + 2\Delta x + 1} + \sqrt{2x + 1}} = \frac{2}{2\sqrt{2x + 1}} = \frac{1}{\sqrt{2x + 1}}$$
3. $f(x) = \sin(3x)$:
   $$\Delta f = \sin(3x + 3\Delta x) - \sin(3x) = 2 \sin\left(\frac{3\Delta x}{2}\right) \cos\left(3x + \frac{3\Delta x}{2}\right)$$
   $$\lim_{\Delta x \to 0} \frac{\Delta f}{\Delta x} = \lim_{\Delta x \to 0} \frac{2 \sin(3\Delta x / 2)}{\Delta x} \cos\left(3x + \frac{3\Delta x}{2}\right) = 2 \cdot \frac{3}{2} \cdot \cos(3x) = 3\cos(3x)$$

#### Решение Задания 2 (Линейная аппроксимация)
1. $\sqrt[4]{16.08}$: функция $f(x) = x^{1/4}$, точка $x_0 = 16$, $\Delta x = 0.08$.  
   $f(16) = 16^{1/4} = 2$.  
   $f'(x) = \frac{1}{4} x^{-3/4} \implies f'(16) = \frac{1}{4 \cdot 8} = \frac{1}{32} = 0.03125$.  
   $$\sqrt[4]{16.08} \approx f(16) + f'(16) \cdot 0.08 = 2 + 0.03125 \cdot 0.08 = 2 + 0.0025 = 2.0025$$
2. $\operatorname{arctg}(1.02)$: функция $f(x) = \operatorname{arctg} x$, $x_0 = 1$, $\Delta x = 0.02$.  
   $f(1) = \operatorname{arctg} 1 = \frac{\pi}{4} \approx 0.785398$.  
   $f'(x) = \frac{1}{1 + x^2} \implies f'(1) = \frac{1}{2} = 0.5$.  
   $$\operatorname{arctg}(1.02) \approx \frac{\pi}{4} + 0.5 \cdot 0.02 = \frac{\pi}{4} + 0.01 \approx 0.7954$$
3. Погрешность объёма шара: $V(R) = \frac{4}{3}\pi R^3$.  
   $dV = V'(R) dR = 4\pi R^2 dR$.  
   При $R = 10$, $dR = 0.05$:  
   $$dV = 4\pi \cdot 100 \cdot 0.05 = 20\pi \approx 62.83 \text{ см}^3$$  
   Относительная погрешность: $\frac{dV}{V} = \frac{4\pi R^2 dR}{\frac{4}{3}\pi R^3} = 3 \frac{dR}{R} = 3 \cdot \frac{0.05}{10} = 1.5\%$.

#### Решение Задания 3 (Касательная и нормаль)
1. $y = x^3 - 3x^2 + 2x$ в $x_0 = 2$:  
   $y(2) = 8 - 12 + 4 = 0$.  
   $y' = 3x^2 - 6x + 2 \implies y'(2) = 12 - 12 + 2 = 2$.  
   Касательная: $y - 0 = 2(x - 2) \implies y = 2x - 4$.  
   Нормаль: $y - 0 = -\frac{1}{2}(x - 2) \implies y = -\frac{1}{2}x + 1$.
2. $y = x^2 - 4x + 3$. Прямая $2x - y + 5 = 0 \iff y = 2x + 5$ имеет угловой коэффициент $k = 2$.  
   Условие параллельности касательной: $y'(x) = 2x - 4 = 2 \implies 2x = 6 \implies x_0 = 3$.  
   $y(3) = 9 - 12 + 3 = 0$. Искомая точка: $(3, 0)$.
3. Графики $y_1 = x^2$ и $y_2 = \sqrt{x}$ в $(1, 1)$:  
   $y'_1(1) = 2x|_{x=1} = 2 = k_1$.  
   $y'_2(1) = \frac{1}{2\sqrt{x}}|_{x=1} = \frac{1}{2} = k_2$.  
   Тангенс угла между касательными:  
   $$\operatorname{tg} \theta = \left|\frac{k_1 - k_2}{1 + k_1 k_2}\right| = \left|\frac{2 - 1/2}{1 + 2 \cdot 1/2}\right| = \frac{3/2}{2} = \frac{3}{4} = 0.75 \implies \theta = \operatorname{arctg}(0.75) \approx 36.87^\circ$$

#### Решение Задания 4 (Дифференцируемость с параметрами)
Функция в окрестности нуля:
* Для непрерывности в $x = 0$:  
  $\lim_{x \to +0} f(x) = \lim_{x \to +0} (x^2 \sin(1/x) + ax + b) = 0 + 0 + b = b$.  
  $f(0) = 0 \implies b = 0$.  
  $\lim_{x \to -0} f(x) = \lim_{x \to -0} (c \cos x + dx) = c \cdot 1 + 0 = c \implies c = 0$.  
  Итак, для непрерывности необходимо $b = 0, c = 0$.
* Для дифференцируемости вычисляем односторонние производные:  
  $f'_+(0) = \lim_{x \to +0} \frac{x^2 \sin(1/x) + ax - 0}{x} = \lim_{x \to +0} (x \sin(1/x) + a) = 0 + a = a$.  
  $f'_-(0) = \lim_{x \to -0} \frac{dx - 0}{x} = d$.  
  Для дифференцируемости необходимо $f'_+(0) = f'_-(0) \implies a = d$.

**Ответ**: Функция дифференцируема на $\mathbb{R}$ при $b = 0, c = 0, a = d \in \mathbb{R}$.

#### Решение Задания 5 (Сложная и обратная функции)
1. Функция: $y = \ln(\sqrt{1 + x^2} - x) + \arcsin\left(\frac{x}{\sqrt{1 + x^2}}\right)$.  
   Заметим, что $\frac{x}{\sqrt{1 + x^2}} = \sin(\operatorname{arctg} x) \implies \arcsin\left(\frac{x}{\sqrt{1 + x^2}}\right) = \operatorname{arctg} x$.  
   Дифференцируем первое слагаемое:  
   $$(\ln(\sqrt{1 + x^2} - x))' = \frac{\frac{2x}{2\sqrt{1 + x^2}} - 1}{\sqrt{1 + x^2} - x} = \frac{\frac{x - \sqrt{1 + x^2}}{\sqrt{1 + x^2}}}{\sqrt{1 + x^2} - x} = -\frac{1}{\sqrt{1 + x^2}}$$  
   Дифференцируем второе слагаемое:  
   $$(\operatorname{arctg} x)' = \frac{1}{1 + x^2}$$  
   Итого: $y' = -\frac{1}{\sqrt{1 + x^2}} + \frac{1}{1 + x^2} = \frac{1 - \sqrt{1 + x^2}}{1 + x^2}$.
2. $f(x) = x^3 + 3x + 1$.  
   $f'(x) = 3x^2 + 3 = 3(x^2 + 1) \ge 3 > 0$ для всех $x \in \mathbb{R}$.  
   Так как $f'(x) > 0$ всюду на $\mathbb{R}$, функция строго возрастает и обратима на $\mathbb{R}$.  
   Найдём точку $x_0$, такую что $f(x_0) = 5$:  
   $$x_0^3 + 3x_0 + 1 = 5 \iff x_0^3 + 3x_0 - 4 = 0$$  
   Корень очевиден: $x_0 = 1$ ($1 + 3 - 4 = 0$).  
   По теореме о производной обратной функции:  
   $$(f^{-1})'(5) = \frac{1}{f'(1)} = \frac{1}{3(1)^2 + 3} = \frac{1}{6}$$
