## ЧАСТЬ III. Подробные решения и ответы

### Ответы на контрольные вопросы

#### Ответ на Вопрос 1 (Геометрия угла касания)
* **Аналитический вывод**: Пусть $\alpha$ — угол наклона касательной к полярной оси $Ox$ ($\operatorname{tg} \alpha = y'_x$), а $\phi$ — полярный угол точки касания. По теореме о внешнем угле треугольника $\alpha = \phi + \mu \implies \mu = \alpha - \phi$.  
  По формуле тангенса разности:
  $$\operatorname{tg} \mu = \frac{\operatorname{tg} \alpha - \operatorname{tg} \phi}{1 + \operatorname{tg} \alpha \operatorname{tg} \phi} = \frac{\dfrac{y'_\phi}{x'_\phi} - \dfrac{\sin\phi}{\cos\phi}}{1 + \dfrac{y'_\phi}{x'_\phi}\dfrac{\sin\phi}{\cos\phi}} = \frac{y'_\phi \cos\phi - x'_\phi \sin\phi}{x'_\phi \cos\phi + y'_\phi \sin\phi}$$
  Подставляя $x'_\phi = r' \cos\phi - r \sin\phi$ и $y'_\phi = r' \sin\phi + r \cos\phi$, получаем:  
  Числитель: $(r' \sin\phi + r \cos\phi)\cos\phi - (r' \cos\phi - r \sin\phi)\sin\phi = r(\cos^2\phi + \sin^2\phi) = r$.  
  Знаменатель: $(r' \cos\phi - r \sin\phi)\cos\phi + (r' \sin\phi + r \cos\phi)\sin\phi = r'(\cos^2\phi + \sin^2\phi) = r'$.  
  Следовательно, $\operatorname{tg} \mu = \frac{r}{r'}$.
* **Геометрический смысл**: Угол $\mu$ характеризует скольжение кривой относительно радиального направления от центра. Если $r' = 0$ (окружность), $\operatorname{tg} \mu = \infty \implies \mu = \frac{\pi}{2}$ (касательная перпендикулярна радиусу).

---

#### Ответ на Вопрос 2 (Логарифмическая спираль)
Уравнение: $r = a e^{k\phi}$. Производная: $r' = k a e^{k\phi} = k r$.  
Тангенс угла касания: $\operatorname{tg} \mu = \frac{r}{k r} = \frac{1}{k} = \operatorname{const}$.  
Поскольку угол $\mu = \operatorname{arctg}(1/k)$ не зависит от полярного угла $\phi$ и постоянен во всех точках кривой, спираль пересекает все радиус-векторы под одним и тем же углом, за что и названа *равноугольной*.  
При $k = 1$: $\operatorname{tg} \mu = 1 \implies \mu = \frac{\pi}{4}$ ($45^\circ$).

---

#### Ответ на Вопрос 3 (Анализ теоремы Ферма)
* **Роль внутренней точки**: В доказательстве мы рассматривали два односторонних предела приращений: справа ($\Delta x > 0 \implies \frac{\Delta f}{\Delta x} \le 0 \implies f'_+(x_0) \le 0$) и слева ($\Delta x < 0 \implies \frac{\Delta f}{\Delta x} \ge 0 \implies f'_-(x_0) \ge 0$). Равенство нулю $f'(x_0) = 0$ возникает исключительно из «зажатия» двусторонней производной между неотрицательным и неположительным односторонними пределами. Это возможно только если точка $x_0$ внутренняя, то есть к ней можно подойти как справа, так и слева.
* **Краевой экстремум**: Для отрезка $[a, b]$ теорема Ферма неверна! Например, функция $f(x) = x$ на $[0, 1]$ достигает максимума в точке $x = 1$, но $f'(1) = 1 \ne 0$. В краевой точке существует лишь односторонняя производная, которая не обязана обращаться в ноль.

---

#### Ответ на Вопрос 4 (Критичность условий теоремы Ролля на $[-1, 1]$)
1. **Разрыв на границе**: $f(x) = x$ при $x \in (-1, 1)$ и $f(-1) = f(1) = 0$. Условия $f(-1) = f(1)$ и дифференцируемость внутри выполнены, но функция разрывна на концах. $f'(x) = 1 \ne 0$ всюду.
2. **Отсутствие дифференцируемости внутри**: $f(x) = 1 - |x|$. Функция непрерывна, $f(-1) = f(1) = 0$, но в точке $x = 0$ недифференцируема. Производная равна $1$ при $x < 0$ и $-1$ при $x > 0$. Нулей нет.
3. **Разные значения на концах**: $f(x) = x$. Непрерывна и дифференцируема, но $f(-1) = -1 \ne f(1) = 1$. $f'(x) = 1 \ne 0$.

---

#### Ответ на Вопрос 5 (Смысл теоремы Лагранжа)
* **Геометрически**: Касательная к графику $y = f(x)$ в точке $(\xi, f(\xi))$ строго параллельна секущей прямой, проходящей через концы графика $A(a, f(a))$ и $B(b, f(b))$.
* **Механически**: Если $s(t)$ — координата тела, то средняя скорость за время $[a, b]$ равна $v_{\text{ср}} = \frac{s(b) - s(a)}{b - a}$. Теорема гарантирует, что спидометр автомобиля хотя бы один раз за поездку показывал ровно среднюю скорость.
* **«Теорема о среднем»**: Производная $f'(\xi)$ принимает среднее значение скорости изменения функции на отрезке.

---

#### Ответ на Вопрос 6 (Критерий постоянства и связность)
* Для связного интервала $(a, b)$: фиксируем точку $x_0 \in (a, b)$. Для любой точки $x \in (a, b)$ по формуле Лагранжа $f(x) - f(x_0) = f'(\xi)(x - x_0) = 0 \cdot (x - x_0) = 0 \implies f(x) = f(x_0) = C$.
* Для несвязного множества $(0, 1) \cup (2, 3)$ свойство **не сохраняется**! Контрпример:
  $$f(x) = \begin{cases} 1, & x \in (0, 1) \\ 2, & x \in (2, 3) \end{cases}$$
  Производная $f'(x) = 0$ всюду в области определения, однако функция не постоянна. Формула Лагранжа применима только на отрезках, целиком лежащих в области определения.

### Решения практических заданий

#### Решение Задания 1 (Полярные координаты)

#### 1. Кардиоида $r = a(1 + \cos\phi)$
* **Производная**: $r'(\phi) = -a \sin\phi$.
* **Угол касания**:
  $$\operatorname{tg} \mu = \frac{r}{r'} = \frac{a(1 + \cos\phi)}{-a \sin\phi} = -\frac{2 \cos^2(\phi/2)}{2 \sin(\phi/2) \cos(\phi/2)} = -\operatorname{ctg}\left(\frac{\phi}{2}\right) = \operatorname{tg}\left(\frac{\phi}{2} + \frac{\pi}{2}\right)$$
  Отсюда $\mu = \frac{\phi}{2} + \frac{\pi}{2}$.
* При $\phi = \frac{\pi}{3}$: $\mu = \frac{\pi}{6} + \frac{\pi}{2} = \frac{2\pi}{3}$ ($120^\circ$), $\operatorname{tg} \mu = -\sqrt{3}$.
* **Вертикальные касательные**: Касательная вертикальна, когда $x'_\phi = 0$ при $y'_\phi \ne 0$.  
  $x(\phi) = r \cos\phi = a(1 + \cos\phi)\cos\phi = a(\cos\phi + \cos^2\phi)$.  
  $$x'_\phi = a(-\sin\phi - 2\cos\phi \sin\phi) = -a \sin\phi (1 + 2\cos\phi) = 0$$
  Корни:
  1. $\sin\phi = 0 \implies \phi = 0$ (точка $(2a, 0)$) или $\phi = \pi$ (полюс, особая точка / касп).
  2. $1 + 2\cos\phi = 0 \implies \cos\phi = -1/2 \implies \phi = \frac{2\pi}{3}$ и $\phi = \frac{4\pi}{3}$.

#### 2. Архимедова спираль $r = a\phi$
* Производная: $r'(\phi) = a$.
* Угол касания: $\operatorname{tg} \mu = \frac{r}{r'} = \frac{a\phi}{a} = \phi$.
* При $\phi \to +\infty$: $\operatorname{tg} \mu = \phi \to +\infty \implies \mu \to \frac{\pi}{2}$.  
  *Вывод*: При удалении от центра витки архимедовой спирали становятся почти перпендикулярными к радиус-векторам (спираль становится похожей на концентрические окружности).

#### Решение Задания 2 (Локальные экстремумы)

#### 1. Функция $f(x) = (x - 1)^2 (x + 2)^3$
Дифференцируем по правилу произведения:
$$f'(x) = 2(x - 1)(x + 2)^3 + 3(x - 1)^2 (x + 2)^2 = (x - 1)(x + 2)^2 \big[ 2(x + 2) + 3(x - 1) \big]$$
$$f'(x) = (x - 1)(x + 2)^2 (5x + 1)$$
Стационарные точки ($f'(x) = 0$):
$$x_1 = -2, \quad x_2 = -\frac{1}{5}, \quad x_3 = 1$$
Исследуем знаки производной $f'(x)$ методом интервалов:
* При $x < -2$: $(-) \cdot (+) \cdot (-) = + \implies f$ возрастает.
* При $-2 < x < -1/5$: $(-) \cdot (+) \cdot (-) = + \implies f$ возрастает.  
  *(Знак не изменился, так как корень $x = -2$ кратности 2; в $x = -2$ экстремума нет!)*
* При $-1/5 < x < 1$: $(-) \cdot (+) \cdot (+) = - \implies f$ убывает.  
  *(Смена знака с $+$ на $-$: в точке $x = -1/5$ **локальный максимум**!)*
* При $x > 1$: $(+) \cdot (+) \cdot (+) = + \implies f$ возрастает.  
  *(Смена знака с $-$ на $+$: в точке $x = 1$ **локальный минимум**!)*

**Ответ**: $x = -\frac{1}{5}$ — точка локального максимума; $x = 1$ — точка локального минимума; $x = -2$ — стационарная точка перегиба.

#### 2. Наибольшее и наименьшее значения $g(x) = x^3 - 3x^2 + 6$ на $[-2, 2]$
1. Стационарные точки: $g'(x) = 3x^2 - 6x = 3x(x - 2) = 0 \implies x = 0$ и $x = 2$. Обе лежат на $[-2, 2]$.
2. Вычисляем значения функции в стационарных точках и на концах отрезка:
   * $g(-2) = (-2)^3 - 3(-2)^2 + 6 = -8 - 12 + 6 = -14$.
   * $g(0) = 0 - 0 + 6 = 6$.
   * $g(2) = 2^3 - 3(2)^2 + 6 = 8 - 12 + 6 = 2$.
3. Сравниваем:
   * $\min_{[-2, 2]} g(x) = -14$ (достигается на левом конце $x = -2$).
   * $\max_{[-2, 2]} g(x) = 6$ (достигается во внутренней точке локального максимума $x = 0$).

#### Решение Задания 3 (Теорема Ролля и нули многочленов)
1. **Уравнение $f(x) = x^5 + 4x - 3 = 0$**:
   * *Существование корня*: Функция $f(x)$ непрерывна на $\mathbb{R}$. $f(0) = -3 < 0$, $f(1) = 2 > 0$. По теореме Больцано — Коши существует корень $x_0 \in (0, 1)$.
   * *Единственность*: Предположим, что существует второй корень $x_1 \ne x_0$. Тогда $f(x_0) = f(x_1) = 0$. По теореме Ролля между ними должна существовать точка $\xi$, в которой $f'(\xi) = 0$.  
     Однако $f'(x) = 5x^4 + 4 \ge 4 > 0$ при всех $x \in \mathbb{R}$. Производная строго положительна и нигде не обращается в ноль! Противоречие. Корень единственный.

2. **Корни производной между корнями функции**:
   Пусть $x_1 < x_2$ — корни функции $f(x)$, то есть $f(x_1) = f(x_2) = 0$.  
   Поскольку $f$ дифференцируема, она непрерывна на $[x_1, x_2]$ и дифференцируема на $(x_1, x_2)$. Все условия теоремы Ролля выполнены.  
   Следовательно, существует $\xi \in (x_1, x_2)$, такое что $f'(\xi) = 0$. $\blacksquare$

3. **Корни $P(x) = x^4 - 4x + c$**:
   Производная: $P'(x) = 4x^3 - 4 = 4(x^3 - 1) = 0 \implies x = 1$ — единственный действительный корень производной.  
   По доказанному свойству многочлен $P(x)$ не может иметь более двух действительных корней (иначе между ними было бы не менее двух корней производной).  
   Минимум функции достигается в точке $x = 1$: $P(1) = 1 - 4 + c = c - 3$.
   * Если $c > 3$: минимум $P(1) > 0 \implies$ график выше оси $Ox$, **действительных корней нет** (0 корней).
   * Если $c = 3$: минимум $P(1) = 0 \implies$ **один корень кратности 2** ($x = 1$).
   * Если $c < 3$: минимум $P(1) < 0 \implies$ ветви уходят в $+\infty$, функция имеет **ровно 2 действительных корня**.

#### Решение Задания 4 (Доказательство неравенств)
1. **Неравенство $|\sin x - \sin y| \le |x - y|$**:  
   При $x = y$ очевидно $0 \le 0$.  
   Пусть $x \ne y$. Для определенности $x < y$. Рассмотрим функцию $f(t) = \sin t$ на отрезке $[x, y]$.  
   Функция дифференцируема на всём $\mathbb{R}$, $f'(t) = \cos t$.  
   По теореме Лагранжа существует $\xi \in (x, y)$, такое что:
   $$\sin y - \sin x = (\cos \xi)(y - x)$$
   Возьмем модуль от обеих частей:
   $$|\sin x - \sin y| = |\cos \xi| \cdot |x - y|$$
   Так как $|\cos \xi| \le 1$ для любого $\xi$:
   $$|\sin x - \sin y| \le 1 \cdot |x - y| = |x - y|$$
   Аналогично для $\operatorname{arctg} t$: производная $(\operatorname{arctg} t)' = \frac{1}{1 + t^2} \le 1$, поэтому:
   $$|\operatorname{arctg} x - \operatorname{arctg} y| = \frac{1}{1 + \xi^2} |x - y| \le |x - y|$$

2. **Неравенство $\frac{b - a}{b} < \ln\left(\frac{b}{a}\right) < \frac{b - a}{a}$ при $0 < a < b$**:  
   Рассмотрим функцию $f(t) = \ln t$ на отрезке $[a, b]$.  
   Она дифференцируема при $t > 0$, $f'(t) = \frac{1}{t}$.  
   По теореме Лагранжа существует $\xi \in (a, b)$, такое что:
   $$\ln b - \ln a = f'(\xi)(b - a) \iff \ln\left(\frac{b}{a}\right) = \frac{b - a}{\xi}$$
   Так как $a < \xi < b$, то для обратных величин выполнено строгое неравенство:
   $$\frac{1}{b} < \frac{1}{\xi} < \frac{1}{a}$$
   Умножая на положительную величину $b - a > 0$:
   $$\frac{b - a}{b} < \frac{b - a}{\xi} < \frac{b - a}{a}$$
   Подставляя $\frac{b - a}{\xi} = \ln(b/a)$, получаем требуемое неравенство:
   $$\frac{b - a}{b} < \ln\left(\frac{b}{a}\right) < \frac{b - a}{a}$$
   Неравенство строго доказано! $\blacksquare$
