## Подробные решения и разборы заданий

### Строгое решение Задания 1.1

1. **Монотонное убывание $\{y_n\}$**:  
   Исследуем отношение соседних членов $\frac{y_{n-1}}{y_n}$:
   $$\frac{y_{n-1}}{y_n} = \frac{\left(1 + \frac{1}{n-1}\right)^n}{\left(1 + \frac{1}{n}\right)^{n+1}} = \frac{\left(\frac{n}{n-1}\right)^n}{\left(\frac{n+1}{n}\right)^{n+1}} = \frac{n^{2n+1}}{(n-1)^n (n+1)^{n+1}} = \frac{n}{n+1} \cdot \left(\frac{n^2}{n^2 - 1}\right)^n = \frac{n}{n+1} \cdot \left(1 + \frac{1}{n^2 - 1}\right)^n$$
   Применим **неравенство Бернулли** $(1 + x)^n > 1 + nx$ для $x = \frac{1}{n^2 - 1} > 0$ и $n \ge 2$:
   $$\left(1 + \frac{1}{n^2 - 1}\right)^n > 1 + \frac{n}{n^2 - 1} > 1 + \frac{n}{n^2} = 1 + \frac{1}{n} = \frac{n+1}{n}$$
   Тогда:
   $$\frac{y_{n-1}}{y_n} > \frac{n}{n+1} \cdot \frac{n+1}{n} = 1 \implies y_{n-1} > y_n$$
   Следовательно, последовательность $\{y_n\}$ строго монотонно убывает.

2. **Двойное неравенство для $e$**:  
   Так как $x_n = (1 + 1/n)^n$ строго возрастает к $e$, то для любого $n$: $x_n < e$.  
   Так как $y_n = (1 + 1/n)^{n+1}$ строго убывает к $e$ (поскольку $\lim y_n = \lim x_n \cdot \lim(1 + 1/n) = e \cdot 1 = e$), то для любого $n$: $e < y_n$.  
   Следовательно:
   $$\left(1 + \frac{1}{n}\right)^n < e < \left(1 + \frac{1}{n}\right)^{n+1}$$

3. **Оценка для логарифма**:  
   Прологарифмируем полученное двойное неравенство по основанию $e$ (функция $\ln x$ строго монотонно возрастает):
   $$\ln\left(1 + \frac{1}{n}\right)^n < \ln e < \ln\left(1 + \frac{1}{n}\right)^{n+1}$$
   $$n \ln\left(1 + \frac{1}{n}\right) < 1 < (n+1) \ln\left(1 + \frac{1}{n}\right)$$
   Разделив первое неравенство на $n$, а второе — на $n+1$, получаем:
   $$\frac{1}{n+1} < \ln\left(1 + \frac{1}{n}\right) < \frac{1}{n} \quad \blacksquare$$

### Строгое доказательство Задания 1.2

Предположим противное: пусть $e$ рационально, то есть $e = \frac{p}{q}$, где $p, q \in \mathbb{N}$, $q \ge 2$.  
Запишем формулу ряда для $e$ при $n = q$:
$$e = 1 + 1 + \frac{1}{2!} + \dots + \frac{1}{q!} + r_q$$
Умножим обе части равенства на $q!$:
$$q! \cdot e = q! \left(1 + 1 + \frac{1}{2!} + \dots + \frac{1}{q!}\right) + q! \cdot r_q$$

Проанализируем компоненты:
1. **Левая часть**: $q! \cdot e = q! \cdot \frac{p}{q} = (q - 1)! \cdot p \in \mathbb{Z}$ — целое число.
2. **Сумма в скобках**: для каждого $k \le q$ число $\frac{q!}{k!} = q(q-1)\dots(k+1) \in \mathbb{Z}$. Следовательно, вся сумма, умноженная на $q!$, является целым числом $M \in \mathbb{Z}$.
3. **Остаток**: отсюда $q! \cdot r_q = q! \cdot e - M$ обязано быть **целым числом**.  
   Но оценим величину $q! \cdot r_q$:
   $$0 < r_q < \frac{1}{q! \cdot q} \implies 0 < q! \cdot r_q < \frac{1}{q} \le \frac{1}{2} < 1$$
   Получаем, что целое число $q! \cdot r_q$ строго заключено в интервале $(0, 1)$, что невозможно!  
Полученное противоречие доказывает, что $e \notin \mathbb{Q}$. $\blacksquare$

### Строгое доказательство Задания 2.1

1. **Иррациональность числа $\pi$ и дробные доли**:  
   Так как число $\pi$ иррационально, число $\frac{1}{2\pi}$ также иррационально.  
   По **теореме Дирихле (или теореме Кронекера)** об аппроксимации иррациональных чисел, множество дробных долей вида:
   $$\left\{ \left\{ \frac{n}{2\pi} \right\} \;\Big|\; n \in \mathbb{N} \right\}$$
   всюду плотно на единичном интервале $[0, 1)$.

2. **Плотность аргументов на окружности**:  
   Умножая на $2\pi$, получаем, что множество точек $\{n \pmod{2\pi} \mid n \in \mathbb{N}\}$ всюду плотно на отрезке $[0, 2\pi]$.  
   Это означает, что для любого угла $\alpha \in [0, 2\pi]$ и для любого сколь угодно малого $\varepsilon > 0$ найдутся натуральные числа $n$ и $m$, такие что:
   $$|n - 2\pi m - \alpha| < \varepsilon$$

3. **Переход к функции синуса**:  
   Функция $\sin x$ непрерывна на $\mathbb{R}$. Возьмем произвольное число $c \in [-1, 1]$.  
   Существует угол $\alpha_0 = \arcsin c \in [-\pi/2, \pi/2]$.  
   В силу плотности множества $\{n - 2\pi m\}$ на числовой прямой мы можем выбрать строго возрастающую последовательность натуральных чисел $n_1 < n_2 < \dots < n_k < \dots$ и целых $m_k$, таких что:
   $$|n_k - 2\pi m_k - \alpha_0| < \frac{1}{k}$$
   Тогда по непрерывности функции $\sin$ и ее $2\pi$-периодичности:
   $$\lim_{k \to \infty} \sin(n_k) = \lim_{k \to \infty} \sin(n_k - 2\pi m_k) = \sin(\alpha_0) = c$$
   Следовательно, любое число $c \in [-1, 1]$ является частичным пределом последовательности $\{\sin n\}$. $\blacksquare$

### Решение к Заданию 2.2

Исследуем поведение последовательности по модулю 4 ($n = 4k, 4k+1, 4k+2, 4k+3$):
1. $n = 4k$:
   $x_{4k} = (-1)^{4k} \frac{4k}{4k+1} + \sin(2\pi k) = 1 \cdot \frac{4k}{4k+1} + 0 \xrightarrow{k \to \infty} 1$.
2. $n = 4k + 1$:
   $x_{4k+1} = (-1)^{4k+1} \frac{4k+1}{4k+2} + \sin\left(2\pi k + \frac{\pi}{2}\right) = -\frac{4k+1}{4k+2} + 1 \xrightarrow{k \to \infty} -1 + 1 = 0$.
3. $n = 4k + 2$:
   $x_{4k+2} = (-1)^{4k+2} \frac{4k+2}{4k+3} + \sin(\pi(2k+1)) = 1 \cdot \frac{4k+2}{4k+3} + 0 \xrightarrow{k \to \infty} 1$.
4. $n = 4k + 3$:
   $x_{4k+3} = (-1)^{4k+3} \frac{4k+3}{4k+4} + \sin\left(2\pi k + \frac{3\pi}{2}\right) = -\frac{4k+3}{4k+4} - 1 \xrightarrow{k \to \infty} -1 - 1 = -2$.

Множество всех частичных пределов состоит из трех значений: $\{-2, 0, 1\}$.  
Следовательно:
$$\varlimsup_{n \to \infty} x_n = \max\{-2, 0, 1\} = 1$$
$$\varunderline{\lim}_{n \to \infty} x_n = \min\{-2, 0, 1\} = -2$$

### Строгое доказательство Задания 3.1

Зафиксируем произвольное $\varepsilon > 0$.  
Пусть $m > n$. Оценим модуль разности $|a_m - a_n|$:
$$|a_m - a_n| = \left| \sum_{k=n+1}^m \frac{\sin(k!)}{k(k+1)} \right| \le \sum_{k=n+1}^m \frac{|\sin(k!)|}{k(k+1)}$$
Так как $|\sin x| \le 1$ для любого $x$:
$$|a_m - a_n| \le \sum_{k=n+1}^m \frac{1}{k(k+1)}$$
Заметим телескопическое разложение: $\frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}$.  
Тогда сумма сворачивается:
$$\sum_{k=n+1}^m \left(\frac{1}{k} - \frac{1}{k+1}\right) = \left(\frac{1}{n+1} - \frac{1}{n+2}\right) + \left(\frac{1}{n+2} - \frac{1}{n+3}\right) + \dots + \left(\frac{1}{m} - \frac{1}{m+1}\right) = \frac{1}{n+1} - \frac{1}{m+1} < \frac{1}{n+1}$$
Нам требуется, чтобы $\frac{1}{n+1} < \varepsilon \iff n > \frac{1}{\varepsilon} - 1$.  
Положим $N(\varepsilon) = \left\lceil \frac{1}{\varepsilon} \right\rceil$.  
Тогда для любых $m > n > N(\varepsilon)$ выполнено:
$$|a_m - a_n| < \frac{1}{n+1} < \varepsilon$$
Последовательность $\{a_n\}$ фундаментальна. По критерию Коши она **сходится**. $\blacksquare$

### Строгое доказательство Задания 3.2

Запишем отрицание критерия Коши:
$$\exists \varepsilon_0 > 0 \; \forall N \in \mathbb{N} \; \exists m > n > N : |b_m - b_n| \ge \varepsilon_0$$
Для любого $N$ выберем $n = N$ и $m = 4N > N$. Тогда:
$$|b_{4N} - b_N| = \sum_{k=N+1}^{4N} \frac{1}{\sqrt{k}}$$
Так как функция $\frac{1}{\sqrt{k}}$ убывает, каждое слагаемое не меньше наименьшего (при $k = 4N$):
$$\sum_{k=N+1}^{4N} \frac{1}{\sqrt{k}} \ge \sum_{k=N+1}^{4N} \frac{1}{\sqrt{4N}} = (4N - N) \cdot \frac{1}{2\sqrt{N}} = \frac{3N}{2\sqrt{N}} = \frac{3}{2}\sqrt{N} \ge \frac{3}{2}$$
Положим $\varepsilon_0 = 1$. Для любого $N \in \mathbb{N}$ при $n = N$ и $m = 4N$:
$$|b_m - b_n| \ge \frac{3}{2} > 1 = \varepsilon_0$$
Условие Коши не выполнено. Следовательно, последовательность $\{b_n\}$ **расходится** к $+\infty$. $\blacksquare$
