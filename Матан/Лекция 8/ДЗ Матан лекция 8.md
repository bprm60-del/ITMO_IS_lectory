## Подробные решения и разборы заданий

### Решение к Заданию 1.1

1. **Доказательство $\lim_{x \to 3} (4x - 5) = 7$**:
   - Нам необходимо для произвольного $\varepsilon > 0$ найти такое $\delta > 0$, чтобы из $0 < |x - 3| < \delta$ следовало:
     $$|(4x - 5) - 7| < \varepsilon$$
   - Преобразуем разность:
     $$|4x - 12| = 4|x - 3| < \varepsilon \iff |x - 3| < \frac{\varepsilon}{4}$$
   - Выбираем $\delta(\varepsilon) = \frac{\varepsilon}{4}$.  
   - Тогда если $0 < |x - 3| < \delta = \frac{\varepsilon}{4}$, то:
     $$|(4x - 5) - 7| = 4|x - 3| < 4 \cdot \frac{\varepsilon}{4} = \varepsilon$$
   - По определению Коши равенство доказано.

2. **Доказательство $\lim_{x \to 2} x^2 = 4$**:
   - Оценим $|x^2 - 4| = |x - 2| \cdot |x + 2|$.
   - Наложим предварительное ограничение: пусть $\delta \le 1$.
   - Если $|x - 2| < 1$, то $1 < x < 3 \implies 3 < x + 2 < 5 \implies |x + 2| < 5$.
   - Тогда:
     $$|x^2 - 4| = |x - 2| \cdot |x + 2| < 5|x - 2|$$
   - Чтобы получить $5|x - 2| < \varepsilon$, достаточно потребовать $|x - 2| < \frac{\varepsilon}{5}$.
   - Выбираем:
     $$\delta(\varepsilon) = \min\left(1, \; \frac{\varepsilon}{5}\right)$$
   - При таком выборе если $0 < |x - 2| < \delta$, то одновременно $|x + 2| < 5$ и $|x - 2| < \frac{\varepsilon}{5}$, откуда:
     $$|x^2 - 4| = |x - 2| \cdot |x + 2| < \frac{\varepsilon}{5} \cdot 5 = \varepsilon$$
   - Предел доказан.

### Решение к Заданию 2.1

1. **Доказательство отсутствия предела $\lim_{x \to 0} \sin\left(\frac{1}{x}\right)$ по Гейне**:
   - Выберем две числовые последовательности аргументов $\{x_n\}$ и $\{y_n\}$, сходящиеся к точке $x_0 = 0$ при $n \to \infty$:
     $$x_n = \frac{1}{\frac{\pi}{2} + 2\pi n}, \quad y_n = \frac{1}{\pi n}, \qquad n \in \mathbb{N}$$
   - Обе последовательности состоят из ненулевых точек и $x_n \to 0$, $y_n \to 0$ при $n \to \infty$.
   - Вычислим значения функции на этих последовательностях:
     $$f(x_n) = \sin\left(\frac{\pi}{2} + 2\pi n\right) = 1 \implies \lim_{n \to \infty} f(x_n) = 1$$
     $$f(y_n) = \sin(\pi n) = 0 \implies \lim_{n \to \infty} f(y_n) = 0$$
   - Получили два различных предельных значения: $1 \ne 0$.
   - По определению Гейне предел существовать не может.

2. **Предел $f(x) = x \sin\left(\frac{1}{x}\right)$ при $x \to 0$**:
   - Так как функция $\sin(t)$ ограничена по модулю единицей: $|\sin(1/x)| \le 1$ для всех $x \ne 0$.
   - Получаем двустороннюю оценку:
     $$-|x| \le x \sin\left(\frac{1}{x}\right) \le |x|$$
   - Поскольку $\lim_{x \to 0} (-|x|) = 0$ и $\lim_{x \to 0} |x| = 0$, по теореме о зажатой функции (Теорема 7) получаем:
     $$\lim_{x \to 0} x \sin\left(\frac{1}{x}\right) = 0$$
   - Альтернативно по Коши: для любого $\varepsilon > 0$ полагаем $\delta(\varepsilon) = \varepsilon$. Тогда при $0 < |x| < \delta$ имеем:
     $$|x \sin(1/x) - 0| \le |x| < \delta = \varepsilon$$

### Решение к Заданию 3.1

1. **Предел $\lim_{x \to 0} x \mathcal{D}(x)$**:
   - Так как $\mathcal{D}(x) \in \{0, 1\}$, то:
     $$0 \le |x \mathcal{D}(x)| \le |x|$$
   - Зададим любое $\varepsilon > 0$. Возьмем $\delta(\varepsilon) = \varepsilon$.
   - Тогда если $0 < |x - 0| < \delta$:
     $$|f(x) - 0| = |x \mathcal{D}(x)| \le |x| < \delta = \varepsilon$$
   - Следовательно, предел существует и равен $0$:
     $$\lim_{x \to 0} x \mathcal{D}(x) = 0$$

2. **Отсутствие предела при $x_0 \ne 0$**:
   - Зафиксируем $x_0 \ne 0$.
   - Выберем рациональную последовательность $\{r_n\} \subset \mathbb{Q} \setminus \{x_0\}$, $r_n \to x_0$, и иррациональную последовательность $\{\xi_n\} \subset (\mathbb{R} \setminus \mathbb{Q}) \setminus \{x_0\}$, $\xi_n \to x_0$.
   - Тогда:
     $$f(r_n) = r_n \cdot 1 = r_n \xrightarrow[n \to \infty]{} x_0$$
     $$f(\xi_n) = \xi_n \cdot 0 = 0 \xrightarrow[n \to \infty]{} 0$$
   - Так как $x_0 \ne 0$, пределы $x_0$ и $0$ не совпадают.
   - По определению Гейне предел $\lim_{x \to x_0} f(x)$ при $x_0 \ne 0$ не существует.

### Решение к Заданию 4.1

1. **Доказательство отделенности от нуля**:
   - Пусть $\lim_{x \to x_0} f(x) = A \ne 0 \implies |A| > 0$.
   - Выберем $\varepsilon = \frac{|A|}{2} > 0$.
   - По определению предела по Коши существует такое $\delta > 0$, что для всех $x \in \dot{U}_\delta(x_0) \cap E$:
     $$|f(x) - A| < \frac{|A|}{2}$$
   - По обратному неравенству треугольника:
     $$|A| - |f(x)| \le |f(x) - A| < \frac{|A|}{2}$$
   - Перенося слагаемые:
     $$|f(x)| > |A| - \frac{|A|}{2} = \frac{|A|}{2}$$
   - Тем самым строго доказано, что $|f(x)| > \frac{|A|}{2}$.

2. **Оценка функции $\frac{1}{f(x)}$**:
   - Из доказанного неравенства следует, что в той же проколотой окрестности знаменатель не обращается в ноль и:
     $$\left| \frac{1}{f(x)} \right| = \frac{1}{|f(x)|} < \frac{1}{\frac{|A|}{2}} = \frac{2}{|A|}$$
   - Обозначив $M = \frac{2}{|A|} > 0$, получаем локальную ограниченность величины $\left|\frac{1}{f(x)}\right| < M$.
