## Задача 1. Кольцо матриц $n \times n$ с вещественными элементами ($M_{n \times n}(\mathbb{R})$)

### (a) Проверка ассоциативности и дистрибутивности умножения

Пусть $A = (a_{ij})$, $B = (b_{ij})$, $C = (c_{ij})$ — матрицы размера $n \times n$ с вещественными элементами ($1 \le i, j \le n$).

#### 1. Ассоциативность умножения: $(A B) C = A (B C)$
По определению матричного умножения:
$$(A B)_{ik} = \sum_{m=1}^n a_{im} b_{mk}$$
Тогда $(i, j)$-й элемент матрицы $(A B) C$ равен:
$$\big((A B) C\big)_{ij} = \sum_{k=1}^n (A B)_{ik} c_{kj} = \sum_{k=1}^n \left( \sum_{m=1}^n a_{im} b_{mk} \right) c_{kj} = \sum_{k=1}^n \sum_{m=1}^n (a_{im} b_{mk}) c_{kj}$$

Аналогично, $(m, j)$-й элемент матрицы $B C$ равен:
$$(B C)_{mj} = \sum_{k=1}^n b_{mk} c_{kj}$$
Тогда $(i, j)$-й элемент матрицы $A (B C)$ равен:
$$\big(A (B C)\big)_{ij} = \sum_{m=1}^n a_{im} (B C)_{mj} = \sum_{m=1}^n a_{im} \left( \sum_{k=1}^n b_{mk} c_{kj} \right) = \sum_{m=1}^n \sum_{k=1}^n a_{im} (b_{mk} c_{kj})$$

Так как в поле вещественных чисел $\mathbb{R}$ умножение ассоциативно ($(a_{im} b_{mk}) c_{kj} = a_{im} (b_{mk} c_{kj})$) и конечные суммы можно переставлять местами, элементы матриц совпадают для всех $i, j$:
$$\big((A B) C\big)_{ij} = \big(A (B C)\big)_{ij} \implies (A B) C = A (B C)$$
Ассоциативность доказана.

---

#### 2. Дистрибутивность умножения относительно сложения

##### Левая дистрибутивность: $A (B + C) = A B + A C$
Элемент суммы матриц: $(B + C)_{kj} = b_{kj} + c_{kj}$.
Вычислим $(i, j)$-й элемент произведения $A (B + C)$:
$$\big(A (B + C)\big)_{ij} = \sum_{k=1}^n a_{ik} (B + C)_{kj} = \sum_{k=1}^n a_{ik} (b_{kj} + c_{kj})$$
Используя дистрибутивность умножения относительно сложения в $\mathbb{R}$:
$$\sum_{k=1}^n (a_{ik} b_{kj} + a_{ik} c_{kj}) = \sum_{k=1}^n a_{ik} b_{kj} + \sum_{k=1}^n a_{ik} c_{kj} = (A B)_{ij} + (A C)_{ij} = (A B + A C)_{ij}$$
Следовательно, $A (B + C) = A B + A C$.

##### Правая дистрибутивность: $(A + B) C = A C + B C$
Вычислим $(i, j)$-й элемент:
$$\big((A + B) C\big)_{ij} = \sum_{k=1}^n (A + B)_{ik} c_{kj} = \sum_{k=1}^n (a_{ik} + b_{ik}) c_{kj} = \sum_{k=1}^n (a_{ik} c_{kj} + b_{ik} c_{kj})$$
$$= \sum_{k=1}^n a_{ik} c_{kj} + \sum_{k=1}^n b_{ik} c_{kj} = (A C)_{ij} + (B C)_{ij} = (A C + B C)_{ij}$$
Следовательно, $(A + B) C = A C + B C$.

Так как аддитивная структура $(M_{n \times n}(\mathbb{R}), +)$ образует абелеву группу, а умножение ассоциативно и дистрибутивно с обеих сторон, $M_{n \times n}(\mathbb{R})$ образует кольцо.

### (b) Будет ли кольцо $M_{n \times n}(\mathbb{R})$ кольцом с единицей?

**Ответ:** Да, будет.

**Доказательство:**
Единичным элементом является единичная матрица $I_n = (\delta_{ij})$, где $\delta_{ij}$ — символ Кронекера:
$$\delta_{ij} = \begin{cases} 1, & i = j \\ 0, & i \ne j \end{cases}$$
Для любой матрицы $A \in M_{n \times n}(\mathbb{R})$:
$$(A I_n)_{ij} = \sum_{k=1}^n a_{ik} \delta_{kj} = a_{ij}$$
$$(I_n A)_{ij} = \sum_{k=1}^n \delta_{ik} a_{kj} = a_{ij}$$
Таким образом, $A I_n = I_n A = A$ для любой матрицы $A$. Нейтральный элемент по умножению существует и равен единичной матрице $I_n$.

---

### (c) Будет ли оно коммутативным кольцом?

**Ответ:** 
* При $n = 1$: **Да** ($M_{1 \times 1}(\mathbb{R}) \cong \mathbb{R}$, умножение чисел коммутативно).
* При $n \ge 2$: **Нет**.

**Доказательство (контрпример для $n \ge 2$):**
Рассмотрим матрицы размера $n \times n$, у которых все элементы, кроме одного, равны нулю:
Пусть $A = E_{12}$ (единица на позиции $(1, 2)$), $B = E_{21}$ (единица на позиции $(2, 1)$):
Для $n = 2$:
$$A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}, \quad B = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}$$
Вычислим произведения:
$$A B = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$$
$$B A = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix} \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}$$
Так как $A B \ne B A$, кольцо не является коммутативным при любом $n \ge 2$.

### (d) Верно ли, что всякий ненулевой элемент кольца $M_{n \times n}(\mathbb{R})$ обратим?

**Ответ:** 
* При $n = 1$: **Верно** (любое ненулевое число $a \ne 0$ обратимо: $a^{-1} = \frac{1}{a}$).
* При $n \ge 2$: **Неверно**.

**Доказательство (контрпример для $n \ge 2$):**
Матрица обратима тогда и только тогда, когда ее определитель отличен от нуля ($\det A \ne 0$).
Рассмотрим ненулевую матрицу:
$$A = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} \ne 0$$
Предположим, что существует обратная матрица $B = \begin{pmatrix} x & y \\ z & w \end{pmatrix}$, такая что $A B = I_2$:
$$A B = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} \begin{pmatrix} x & y \\ z & w \end{pmatrix} = \begin{pmatrix} x & y \\ 0 & 0 \end{pmatrix}$$
Но единичная матрица имеет вид $I_2 = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$. Элемент во второй строке и втором столбце равен $0 \ne 1$. Равенство $A B = I_2$ невозможно ни при каких $x, y, z, w$. Следовательно, матрица $A$ необратима.

### (e) Вывод формулы обратной матрицы для матриц $2 \times 2$

Пусть задана матрица $A = \begin{pmatrix} a & b \\ c & d \end{pmatrix} \in M_{2 \times 2}(\mathbb{R})$.
Ищем матрицу $B = \begin{pmatrix} x & y \\ z & w \end{pmatrix}$, такую что:
$$A B = I_2 \iff \begin{pmatrix} a & b \\ c & d \end{pmatrix} \begin{pmatrix} x & y \\ z & w \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$$

Перемножая матрицы, получаем систему из четырех уравнений относительно $x, y, z, w$:
$$\begin{cases} ax + bz = 1 \\ cx + dz = 0 \end{cases} \quad \text{и} \quad \begin{cases} ay + bw = 0 \\ cy + dw = 1 \end{cases}$$

#### 1. Решение первой системы:
Умножим первое уравнение на $d$, а второе на $b$:
$$\begin{cases} adx + bdz = d \\ bcx + bdz = 0 \end{cases}$$
Вычитая второе уравнение из первого:
$$(ad - bc) x = d$$
Аналогично, умножим первое уравнение на $c$, а второе на $a$:
$$\begin{cases} acx + bcz = c \\ acx + adz = 0 \end{cases}$$
Вычитая первое из второго:
$$(ad - bc) z = -c$$

#### 2. Решение второй системы:
Аналогичными действиями получаем:
$$(ad - bc) y = -b$$
$$(ad - bc) w = a$$

Обозначим определитель матрицы: $\det A = ad - bc$.  
Если $\det A = ad - bc \ne 0$, то система имеет единственное решение:
$$x = \frac{d}{ad - bc}, \quad y = -\frac{b}{ad - bc}, \quad z = -\frac{c}{ad - bc}, \quad w = \frac{a}{ad - bc}$$

Следовательно, матрица $B$ имеет вид:
$$B = \frac{1}{ad - bc} \begin{pmatrix} d & -b \\ -c & a \end{pmatrix}$$

#### Проверка второго условия $B A = I_2$:
$$B A = \frac{1}{ad - bc} \begin{pmatrix} d & -b \\ -c & a \end{pmatrix} \begin{pmatrix} a & b \\ c & d \end{pmatrix} = \frac{1}{ad - bc} \begin{pmatrix} da - bc & db - bd \\ -ca + ac & -cb + ad \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} = I_2$$

**Итоговая формула:**
$$A^{-1} = \frac{1}{ad - bc} \begin{pmatrix} d & -b \\ -c & a \end{pmatrix} \quad (\text{при } ad - bc \ne 0)$$

## Задача 2. Исследование множеств с операциями

### (a) Множество $\mathbb{N}$ со стандартными операциями $+$ и $\cdot$
* **Кольцо:** **Нет**.  
  *Доказательство:* В кольце множество по сложению обязано быть абелевой группой. В $\mathbb{N} = \{1, 2, 3, \dots\}$ для элемента $a \in \mathbb{N}$ не существует противоположного элемента $-a$ (так как $-a \notin \mathbb{N}$). Аксиома существования обратного по сложению не выполняется.
* **Кольцо с единицей:** Нет.
* **Коммутативное кольцо:** Нет.
* **Поле:** Нет.
* **Множество обратимых элементов:** Не применимо (не является кольцом с единицей).

---

### (b) Множество $\mathbb{Z}$ со стандартными операциями $+$ и $\cdot$
* **Кольцо:** **Да**.  
  * $(\mathbb{Z}, +)$ — абелева группа (нейтральный $0$, противоположный $-a$);
  * Умножение ассоциативно;
  * Дистрибутивность умножения относительно сложения выполняется.
* **Кольцо с единицей:** **Да**, единица $1 \in \mathbb{Z}$ ($1 \cdot a = a \cdot 1 = a$).
* **Коммутативное кольцо:** **Да**, $a \cdot b = b \cdot a$ для любых целых чисел.
* **Поле:** **Нет**.  
  *Доказательство:* Не всякий ненулевой элемент обратим. Например, для числа $2 \in \mathbb{Z}$ обратный по умножению элемент $\frac{1}{2} \notin \mathbb{Z}$.
* **Множество обратимых элементов:**
  Элемент $a \in \mathbb{Z}$ обратим, если существует $b \in \mathbb{Z}$, такой что $a \cdot b = 1$. Это возможно только при $a = 1$ или $a = -1$.
  $$U(\mathbb{Z}) = \{1, -1\}$$

---

### (c) Множество $2\mathbb{Z}$ (четных чисел) со стандартными операциями $+$ и $\cdot$
* **Кольцо:** **Да**.  
  * $(2\mathbb{Z}, +)$ — абелева группа (сумма четных четна, $0 \in 2\mathbb{Z}$, противоположное к четному четно);
  * Произведение двух четных четно: $(2k)(2m) = 2(2km) \in 2\mathbb{Z}$, операция замкнута и ассоциативна;
  * Дистрибутивность наследуется из $\mathbb{Z}$.
* **Кольцо с единицей:** **Нет**.  
  *Доказательство:* Предположим, существует нейтральный по умножению элемент $e \in 2\mathbb{Z}$. Тогда $e \cdot 2 = 2 \implies 2e = 2 \implies e = 1$. Но $1 \notin 2\mathbb{Z}$ (нечетное число).
* **Коммутативное кольцо:** **Да**, $a \cdot b = b \cdot a$.
* **Поле:** **Нет** (нет единицы).
* **Множество обратимых элементов:** Не применимо (кольцо без единицы).

---

### (d) Множество $\mathbb{Q}$ со стандартными операциями $+$ и $\cdot$
* **Кольцо:** **Да**.
* **Кольцо с единицей:** **Да**, единица $1 \in \mathbb{Q}$.
* **Коммутативное кольцо:** **Да**.
* **Поле:** **Да**.  
  *Доказательство:* Любое ненулевое рациональное число представляется в виде $q = \frac{m}{n}$, где $m, n \in \mathbb{Z}$, $m \ne 0, n \ne 0$. Обратным элементом по умножению является $q^{-1} = \frac{n}{m} \in \mathbb{Q}$, при этом $q \cdot q^{-1} = \frac{m}{n} \cdot \frac{n}{m} = 1$.
* **Множество обратимых элементов:**
  Все элементы, кроме нуля:
  $$U(\mathbb{Q}) = \mathbb{Q} \setminus \{0\}$$

---

### (e) Множество подмножеств $\mathcal{P}(\mathbb{R})$ с операциями $\oplus = \cup$ (сложение) и $\odot = \cap$ (умножение)
* **Кольцо:** **Нет**.  
  *Доказательство:* Проверим, образует ли $(\mathcal{P}(\mathbb{R}), \cup)$ группу по «сложению»:
  1. Нейтральным элементом по объединению является пустое множество $\varnothing$, так как $A \cup \varnothing = A$ для любого $A \subseteq \mathbb{R}$.
  2. Для того чтобы элемент $B$ был противоположным к $A$, должно выполняться $A \cup B = \varnothing$.
  3. Но если $A \ne \varnothing$, то для любого подмножества $B$ выполнено $A \cup B \supseteq A \ne \varnothing$. Следовательно, ни для одного непустого множества $A$ не существует противоположного элемента.
  Аксиома существования обратного по сложению нарушена.
* **Кольцо с единицей:** Нет.
* **Коммутативное кольцо:** Нет.
* **Поле:** Нет.
* **Множество обратимых элементов:** Не применимо.

---

### (f) Множество подмножеств $\mathcal{P}(\mathbb{R})$ с операциями $\oplus = \Delta$ (симметрическая разность) и $\odot = \cap$ (пересечение)
* **Кольцо:** **Да** (Булево кольцо).  
  *Доказательство:*
  1. $(\mathcal{P}(\mathbb{R}), \Delta)$ — абелева группа:
     * Ассоциативность: $(A \Delta B) \Delta C = A \Delta (B \Delta C)$;
     * Коммутативность: $A \Delta B = B \Delta A$;
     * Нейтральный элемент («ноль» кольца): пустое множество $\varnothing$, так как $A \Delta \varnothing = (A \setminus \varnothing) \cup (\varnothing \setminus A) = A$;
     * Противоположный элемент: каждый элемент противоположен сам себе, так как $A \Delta A = (A \setminus A) \cup (A \setminus A) = \varnothing$. То есть $-A = A$.
  2. Умножение $\cap$ ассоциативно: $(A \cap B) \cap C = A \cap (B \cap C)$.
  3. Дистрибутивность $\cap$ относительно $\Delta$:
     $$A \cap (B \Delta C) = (A \cap B) \Delta (A \cap C)$$
* **Кольцо с единицей:** **Да**.  
  Единицей является всё множество $\mathbb{R}$, так как для любого $A \subseteq \mathbb{R}$ выполнено:
  $$A \cap \mathbb{R} = A$$
* **Коммутативное кольцо:** **Да**, $A \cap B = B \cap A$.
* **Поле:** **Нет**.  
  *Доказательство:* Для того чтобы элемент $A \ne \varnothing$ был обратим, должно существовать подмножество $B$, такое что $A \cap B = \mathbb{R}$. Однако $A \cap B \subseteq A$. Если $A \ne \mathbb{R}$ (например, $A = \{0\}$), то $A \cap B \subseteq \{0\} \ne \mathbb{R}$. Значит, любое собственное непустое подмножество необратимо.
* **Множество обратимых элементов:**
  Единственным обратимым элементом является единица кольца:
  $$U(\mathcal{P}(\mathbb{R})) = \{\mathbb{R}\}$$

### (g) Множество многочленов $\mathbb{R}[x]$ со стандартными операциями $+$ и $\cdot$
* **Кольцо:** **Да**.  
  $(\mathbb{R}[x], +)$ — абелева группа (ноль — нулевой многочлен $0$, противоположный к $P(x)$ — $-P(x)$). Умножение многочленов ассоциативно и дистрибутивно относительно сложения.
* **Кольцо с единицей:** **Да**, единица — многочлен нулевой степени $E(x) \equiv 1$.
* **Коммутативное кольцо:** **Да**, $P(x) \cdot Q(x) = Q(x) \cdot P(x)$.
* **Поле:** **Нет**.  
  *Доказательство:* Многочлены положительной степени необратимы. При умножении многочленов степени складываются: $\deg(P \cdot Q) = \deg P + \deg Q$. Если $\deg P \ge 1$, то для любого ненулевого $Q$ имеем $\deg(P \cdot Q) \ge 1 \ne 0 = \deg(1)$. Значит, равенство $P \cdot Q = 1$ невозможно.
* **Множество обратимых элементов:**
  Обратимы в точности ненулевые многочлены нулевой степени (ненулевые константы):
  $$U(\mathbb{R}[x]) = \mathbb{R}[x]^\times = \mathbb{R} \setminus \{0\}$$

---

### (h) Множество многочленов $I_5 = \{P(x) \in \mathbb{R}[x] \mid P(5) = 0\}$ со стандартными операциями
* **Кольцо:** **Да**.  
  *Доказательство:*
  * Сложение замкнуто: если $P(5) = 0$ и $Q(5) = 0$, то $(P + Q)(5) = P(5) + Q(5) = 0 + 0 = 0 \implies P + Q \in I_5$.
  * Нулевой многочлен лежит в $I_5$: $0(5) = 0$.
  * Противоположный лежит в $I_5$: $(-P)(5) = -P(5) = 0$.
  * Умножение замкнуто: $(P \cdot Q)(5) = P(5) \cdot Q(5) = 0 \cdot 0 = 0 \implies P \cdot Q \in I_5$.
  * Ассоциативность и дистрибутивность наследуются из $\mathbb{R}[x]$.
* **Кольцо с единицей:** **Нет**.  
  *Доказательство:* Предположим, что существует нейтральный элемент по умножению $E(x) \in I_5$.  
  Так как $E \in I_5$, по определению множества должно выполняться $E(5) = 0$.  
  С другой стороны, для любого многочлена $P \in I_5$ должно выполняться $E(x) P(x) = P(x)$.  
  Возьмем многочлен $P(x) = x - 5 \in I_5$. Тогда:
  $$E(x)(x - 5) = x - 5 \implies (E(x) - 1)(x - 5) = 0$$
  Так как кольцо многочленов $\mathbb{R}[x]$ не имеет делителей нуля, получаем $E(x) \equiv 1$.  
  Но тогда $E(5) = 1 \ne 0$, что противоречит условию $E \in I_5$. Следовательно, единицы в данном кольце не существует.
* **Коммутативное кольцо:** **Да**, $P(x) Q(x) = Q(x) P(x)$.
* **Поле:** **Нет** (кольцо без единицы).
* **Множество обратимых элементов:** Не применимо.

### (i) Множество $\{0, 1, 2, 3, 4\} = \mathbb{Z}_5$ с операциями сложения и умножения по модулю 5
* **Кольцо:** **Да** (кольцо вычетов).
* **Кольцо с единицей:** **Да**, единица равна $1$.
* **Коммутативное кольцо:** **Да**.
* **Поле:** **Да**.  
  *Доказательство:* Модуль $p = 5$ — простое число. Для любого ненулевого элемента существует обратный по умножению в $\mathbb{Z}_5$:
  * $1 \cdot 1 = 1 \equiv 1 \pmod 5 \implies 1^{-1} = 1$;
  * $2 \cdot 3 = 6 \equiv 1 \pmod 5 \implies 2^{-1} = 3$;
  * $3 \cdot 2 = 6 \equiv 1 \pmod 5 \implies 3^{-1} = 2$;
  * $4 \cdot 4 = 16 \equiv 1 \pmod 5 \implies 4^{-1} = 4$.
  Каждый ненулевой элемент обратим, следовательно, $\mathbb{Z}_5$ — поле ($\mathbb{F}_5$).
* **Множество обратимых элементов:**
  $$U(\mathbb{Z}_5) = \{1, 2, 3, 4\}$$

### (j) Множество $\{0, 1, 2, 3, 4, 5\} = \mathbb{Z}_6$ с операциями сложения и умножения по модулю 6
* **Кольцо:** **Да** (кольцо вычетов).
* **Кольцо с единицей:** **Да**, единица равна $1$.
* **Коммутативное кольцо:** **Да**.
* **Поле:** **Нет**.  
  *Доказательство:* Число $6 = 2 \cdot 3$ составное. В кольце $\mathbb{Z}_6$ присутствуют делители нуля:
  $$2 \cdot 3 = 6 \equiv 0 \pmod 6, \quad \text{где } 2 \ne 0, \; 3 \ne 0$$
  В любом поле делители нуля отсутствуют, следовательно, $\mathbb{Z}_6$ не является полем.
* **Множество обратимых элементов:**
  Обратимы в точности те элементы, которые взаимно просты с модулем 6 ($\operatorname{НОД}(a, 6) = 1$):
  * $1 \cdot 1 = 1 \equiv 1 \pmod 6 \implies 1^{-1} = 1$;
  * $5 \cdot 5 = 25 \equiv 1 \pmod 6 \implies 5^{-1} = 5$;
  * Элементы $2, 3, 4$ необратимы (делители нуля: $2 \cdot 3 \equiv 0$, $4 \cdot 3 = 12 \equiv 0$).
  $$U(\mathbb{Z}_6) = \{1, 5\}$$

## Задача 3. Подполя поля рациональных чисел $\mathbb{Q}$

### Формулировка
Пусть $K$ — поле. Подмножество $L \subset K$ называется подполем поля $K$, если оно замкнуто относительно операций поля $K$ и само является полем (с теми же операциями).  
**Требуется найти все подполя поля $\mathbb{Q}$.**

---

### Решение

Пусть $L \subseteq \mathbb{Q}$ — произвольное подполе поля рациональных чисел $\mathbb{Q}$.

1. **Единица поля лежит в $L$:**  
   По определению поля в $L$ обязан существовать ненулевой нейтральный элемент по умножению $1_L \in L$.  
   Так как $1_L \in \mathbb{Q}$, для любого ненулевого $x \in L$ выполнено:
   $$x \cdot 1_L = x = x \cdot 1_\mathbb{Q}$$
   По закону сокращения в поле $\mathbb{Q}$ получаем:
   $$1_L = 1_\mathbb{Q} = 1 \in L$$

2. **Все целые числа принадлежат $L$ ($\mathbb{Z} \subseteq L$):**  
   Поле $L$ замкнуто относительно сложения:
   * $1 \in L \implies 1 + 1 = 2 \in L \implies 2 + 1 = 3 \in L \implies \dots \implies n \in L$ для любого натурального $n \in \mathbb{N}$ (по индукции).
   * Поле $L$ является группой по сложению, следовательно, для каждого $n \in L$ существует противоположный элемент $-n \in L$, а также нейтральный элемент по сложению $0 \in L$.
   Таким образом, все целые числа лежат в $L$:
   $$\mathbb{Z} \subseteq L$$

3. **Обратные к целым числам принадлежат $L$:**  
   Так как $L$ — поле, каждый его ненулевой элемент обратим в $L$.  
   Для любого целого $m \in \mathbb{Z} \setminus \{0\}$ имеем $m \in L \setminus \{0\}$, следовательно:
   $$\frac{1}{m} = m^{-1} \in L$$

4. **Все рациональные числа принадлежат $L$ ($\mathbb{Q} \subseteq L$):**  
   Поле $L$ замкнуто относительно умножения. Возьмем произвольное число $q \in \mathbb{Q}$. По определению рационального числа, $q = \frac{k}{m}$, где $k \in \mathbb{Z}$, $m \in \mathbb{Z} \setminus \{0\}$.  
   Так как $k \in L$ и $\frac{1}{m} \in L$, их произведение также лежит в $L$:
   $$q = k \cdot \frac{1}{m} \in L \implies \mathbb{Q} \subseteq L$$

5. **Итог:**  
   Мы получили, что с одной стороны $L \subseteq \mathbb{Q}$ (по определению подмножества), а с другой стороны $\mathbb{Q} \subseteq L$.  
   Следовательно:
   $$L = \mathbb{Q}$$

### Ответ:
Поле $\mathbb{Q}$ имеет единственное подполе — само поле $\mathbb{Q}$ (собственных подполей не существует; поле $\mathbb{Q}$ является простым полем).
