Аксиомы линейного пространства 

Линейным пространством называется непустое множество элементов (векторов)
с двумя бинарными операциями сложения и вычитания на элементах поля K

Пусть V - линейное пространства x,y,z $\in$ V $\alpha, \beta \in K$ 
Аксиомы:
	Для любых x,y x+y = y+x по умножению
	Выполняется ассоциативность по умножению
	Существование нейтрального элемента по сложению
	Существование обратного элемента по сложению
	Для любых a, b из поля k $a*(b*x) = (a*b)*x$ 
	$1 \in K$  1*x = x
	Дистрибутивность умножения относительно сложения
	Дистрибутивность сложения относительно умножения. 

Следствия из аксиом:
	Каждую из аксиом выпиши в дз. (попроси доказательство)
	Единственность нулевого вектора
	Единственность обратного по сложению
	Для любого вектора. его умножение на 0 даёт 0

Важнейшие примеры линейных пространств:
	1. Арифметическое линейное пространство $K^n$ ($R^n$, $C^n$) K^n = V = {a_1, a_2, a_3, ... , a_n | a_i in K} . Сложение по элементное. Умножение на элемент k по элементное. (Проверить все аксиомы на арифметическом линейном пространстве - УПРАЖНЕНИЕ)
	2. Пространство многочленов ($K[x]$ пространство всех многочленов от x с коэффициентами поля K) 
	3. Пространство матриц. 

Прямоугольная матрица над полем K. 
Определение: Прямоугольной матрицей размерности m на n называется таблица элементов поля K состоящая из m строк и n столбцов. $(m, n \in N)$ 
Матрице дают название большими латинскими буквами
A = ($a_{1,1}$ , $a_{1,2}$ .... $a_{m,n}$) изображают в виде прямоугольной матрицы (изобрази)

$M_{m,n}$ - матрица m на n
Линейные операции над матрицами 
	Сложение происходит по элементно
	Умножение происходит по элементно
