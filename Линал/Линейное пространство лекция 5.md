Определение $[x_1,x_2,x_3, ..., x_k] \subset V, [a_1,a_2,a_3, ..., a_k] \subset K$ (V - линейное пространство называется K) 
Линейной комбинацией называется $a_1*x_1+a_2*x_2+...+a_k*x_k = \sum (i=1-> k) a_i*x_i$ 
$a_i$ называются коэффициентами линейной комбинацией

Определение:
Лин комбинация называется тривиальной где все $a_i$ = 0

Система векторов {x1,x2, xk} \subset V называется линейно независимой, если из равенства линейной комбинации этих веrторов 0, следует что эта линейная комбинация тривиальная

Система векторов называется линейно зависимой, если существует нетривиальная линейная комбинация равная 0
(существует ai != 0; но при этом сумма = 0)

Теорема:
линейное пространство линейно зависимо, если один векторов равен множеству комбинации остальных
Доказательство: Докажи остаток

Применение:
R^2 x1 = (2 -4); x2 = (-6 12)
x2 = -3 => {x1, x2} линейно зависимые

Теорема:
	Критерий подпространства
Непустое подмножество называется линейным подпространством V:
1) $\forall x, y \in L$  $x+y\in L$ 
2) $\forall a \in L, \forall x \in L, a*x \in L$
