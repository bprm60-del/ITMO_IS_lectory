### Задача 1. Вычислите

#### (a) Вычислить $\left(\dfrac{4}{\sqrt{3}+i}\right)^2$

**Решение:**
1. Преобразуем дробь в скобках, домножив числитель и знаменатель на комплексно сопряженное к знаменателю число $\sqrt{3} - i$:
   $$\frac{4}{\sqrt{3}+i} = \frac{4(\sqrt{3} - i)}{(\sqrt{3}+i)(\sqrt{3}-i)} = \frac{4(\sqrt{3} - i)}{(\sqrt{3})^2 - i^2} = \frac{4(\sqrt{3} - i)}{3 - (-1)} = \frac{4(\sqrt{3} - i)}{4} = \sqrt{3} - i$$

2. Возведем полученное число в квадрат:
   $$\left(\sqrt{3} - i\right)^2 = (\sqrt{3})^2 - 2\sqrt{3}i + i^2 = 3 - 2\sqrt{3}i - 1 = 2 - 2\sqrt{3}i$$

*Альтернативный способ (в тригонометрической форме):*
* $|4| = 4, \quad \arg(4) = 0 \implies 4 = 4 e^{i \cdot 0}$;
* $|\sqrt{3}+i| = \sqrt{3+1} = 2, \quad \arg(\sqrt{3}+i) = \frac{\pi}{6} \implies \sqrt{3}+i = 2 e^{i\pi/6}$;
* $\dfrac{4}{\sqrt{3}+i} = \dfrac{4 e^{i \cdot 0}}{2 e^{i\pi/6}} = 2 e^{-i\pi/6}$;
* $\left(2 e^{-i\pi/6}\right)^2 = 4 e^{-i\pi/3} = 4\left(\cos\left(-\frac{\pi}{3}\right) + i\sin\left(-\frac{\pi}{3}\right)\right) = 4\left(\frac{1}{2} - i\frac{\sqrt{3}}{2}\right) = 2 - 2\sqrt{3}i$.

**Ответ:** $2 - 2\sqrt{3}i$.

#### (b) Вычислить $\sqrt{2 - 2\sqrt{3}i}$

**Решение:**
Требуется найти все комплексные значения квадратного корня из числа $w = 2 - 2\sqrt{3}i$.

1. Заметим, что из пункта (a) мы уже знаем, что $(\sqrt{3} - i)^2 = 2 - 2\sqrt{3}i$. Следовательно, одним из корней является $u_1 = \sqrt{3} - i$, а вторым — противоположное ему число $u_2 = -u_1 = -\sqrt{3} + i$.

2. Проверим результат по общей формуле корней в тригонометрической форме:
   * Модуль: $|w| = \sqrt{2^2 + (-2\sqrt{3})^2} = \sqrt{4 + 12} = \sqrt{16} = 4$.
   * Аргумент: $\cos\phi = \frac{2}{4} = \frac{1}{2}, \; \sin\phi = -\frac{2\sqrt{3}}{4} = -\frac{\sqrt{3}}{2} \implies \phi = -\frac{\pi}{3}$.
   * Корни степени $n = 2$:
     $$u_k = \sqrt{4} \left(\cos\frac{-\frac{\pi}{3} + 2\pi k}{2} + i\sin\frac{-\frac{\pi}{3} + 2\pi k}{2}\right) = 2 \left(\cos\left(-\frac{\pi}{6} + \pi k\right) + i\sin\left(-\frac{\pi}{6} + \pi k\right)\right)$$
   * При $k = 0$:
     $$u_0 = 2\left(\cos\left(-\frac{\pi}{6}\right) + i\sin\left(-\frac{\pi}{6}\right)\right) = 2\left(\frac{\sqrt{3}}{2} - \frac{1}{2}i\right) = \sqrt{3} - i$$
   * При $k = 1$:
     $$u_1 = 2\left(\cos\frac{5\pi}{6} + i\sin\frac{5\pi}{6}\right) = 2\left(-\frac{\sqrt{3}}{2} + \frac{1}{2}i\right) = -\sqrt{3} + i$$

**Ответ:** $\pm(\sqrt{3} - i)$, то есть $\sqrt{3} - i$ и $-\sqrt{3} + i$.

#### (c) Вычислить $(1 + \sqrt{3}i)^{15}$

**Решение:**
1. Запишем число $z = 1 + \sqrt{3}i$ в показательной (или тригонометрической) форме:
   * Модуль: $|z| = \sqrt{1^2 + (\sqrt{3})^2} = \sqrt{1 + 3} = 2$.
   * Аргумент: $\cos\phi = \frac{1}{2}, \; \sin\phi = \frac{\sqrt{3}}{2} \implies \phi = \frac{\pi}{3}$.
   * Следовательно, $z = 2 e^{i\pi/3} = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)$.

2. Применим формулу Муавра для степени $n = 15$:
   $$z^{15} = \left(2 e^{i\pi/3}\right)^{15} = 2^{15} \cdot e^{i \cdot 15 \cdot \frac{\pi}{3}} = 2^{15} \cdot e^{i \cdot 5\pi}$$
   $$e^{i \cdot 5\pi} = \cos(5\pi) + i\sin(5\pi) = -1 + 0i = -1$$

3. Вычисляем итоговое значение:
   $$z^{15} = 2^{15} \cdot (-1) = -32768$$

**Ответ:** $-32768$ (или $-2^{15}$).

#### (d) Вычислить $(\cos(2\phi) + i\sin(2\phi) - 1)^n$, $n \in \mathbb{N}$

**Решение:**
1. Преобразуем основание степени:
   $$w = \cos(2\phi) - 1 + i\sin(2\phi)$$
   Используем формулы половинного угла и двойного угла:
   $$\cos(2\phi) - 1 = - (1 - \cos(2\phi)) = -2\sin^2\phi$$
   $$\sin(2\phi) = 2\sin\phi\cos\phi$$

2. Подставим в выражение:
   $$w = -2\sin^2\phi + 2i\sin\phi\cos\phi = 2\sin\phi \cdot (-\sin\phi + i\cos\phi)$$

3. Заметим, что $-\sin\phi + i\cos\phi = i(\cos\phi + i\sin\phi) = i e^{i\phi}$:
   $$w = 2\sin\phi \cdot i e^{i\phi}$$
   Поскольку $i = e^{i\pi/2}$, основание можно представить в виде:
   $$w = 2\sin\phi \cdot e^{i\left(\phi + \frac{\pi}{2}\right)}$$

4. Возводим в натуральную степень $n$:
   $$w^n = (2\sin\phi \cdot i e^{i\phi})^n = (2\sin\phi)^n \cdot i^n \cdot e^{i n\phi} = (2\sin\phi)^n \cdot i^n \cdot (\cos(n\phi) + i\sin(n\phi))$$

   Или, объединяя в аргумент косинуса и синуса:
   $$w^n = (2\sin\phi)^n \left[\cos\left(n\phi + \frac{n\pi}{2}\right) + i\sin\left(n\phi + \frac{n\pi}{2}\right)\right]$$

   В зависимости от остатка от деления $n$ на $4$ ($i^n$):
   * Если $n = 4k$: $i^n = 1 \implies (2\sin\phi)^n (\cos(n\phi) + i\sin(n\phi))$;
   * Если $n = 4k+1$: $i^n = i \implies (2\sin\phi)^n (-\sin(n\phi) + i\cos(n\phi))$;
   * Если $n = 4k+2$: $i^n = -1 \implies -(2\sin\phi)^n (\cos(n\phi) + i\sin(n\phi))$;
   * Если $n = 4k+3$: $i^n = -i \implies (2\sin\phi)^n (\sin(n\phi) - i\cos(n\phi))$.

**Ответ:** $(2\sin\phi)^n \left[\cos\left(n\phi + \dfrac{n\pi}{2}\right) + i\sin\left(n\phi + \dfrac{n\pi}{2}\right)\right] = (2\sin\phi)^n \cdot i^n (\cos(n\phi) + i\sin(n\phi))$.

### Задача 2. Изобразите на комплексной плоскости множество

#### (a) $\{z \in \mathbb{C} \mid \arg(z) = |z|\}$

**Решение:**
1. Перейдем к полярным координатам на комплексной плоскости: $z = r e^{i\theta}$, где $r = |z| \ge 0$, $\theta = \arg(z)$.
2. Заданное условие принимает вид:
   $$r = \theta$$
   Это классическое уравнение **спирали Архимеда** в полярных координатах.
3. Поскольку радиус-вектор неотрицателен ($r \ge 0$), то и угол $\theta \ge 0$.
   * **При стандартном соглашении о главном значении аргумента** $\arg(z) \in [0, 2\pi)$:  
     Угол изменяется от $0$ до $2\pi$. При $\theta = 0$ имеем $r = 0$ (точка $z = 0$, начало координат). По мере возрастания $\theta$ точка удаляется от начала координат пропорционально углу поворота и при $\theta \to 2\pi$ приближается к точке $z = 2\pi$ на положительной вещественной полуоси. Это **один полный виток архимедовой спирали**, начинающийся в $0$ и заканчивающийся в точке $2\pi$.
     *(Если главное значение выбирается в интервале $(-\pi, \pi]$, то в силу $r \ge 0$ допустим отрезок $\theta \in [0, \pi]$, что соответствует половине витка спирали от $0$ до точки $-\pi$ на вещественной оси).*
   * **При рассмотрении общего многозначного аргумента** $\operatorname{Arg}(z)$:  
     Множество представляет собой бесконечную раскручивающуюся **спираль Архимеда** $r = \theta$ ($\theta \ge 0$). Расстояние между соседними витками вдоль любого луча постоянно и равно $2\pi$.

```
             Im
              |         * (виток спирали)
              |     *       *
              |   *           *
     ---------+--*-------------*----> Re
            0 | *               2π
              |
```

#### (b) $\{z \in \mathbb{C} \mid |z - z_1| = |z - z_2|\}$, где $z_1, z_2 \in \mathbb{C}$ — фиксированные комплексные числа

**Решение:**
1. Геометрический смысл модуля разности $|z - w|$: это евклидово расстояние между точками $z$ и $w$ на комплексной плоскости.
2. Уравнение $|z - z_1| = |z - z_2|$ означает:
   $$\operatorname{dist}(z, z_1) = \operatorname{dist}(z, z_2)$$
   То есть точка $z$ равноудалена от двух фиксированных точек $z_1$ и $z_2$.

3. **Случай 1: $z_1 \ne z_2$.**  
   Геометрическим местом точек, равноудаленных от двух заданных точек, является **срединный перпендикуляр** к отрезку $[z_1, z_2]$.  
   * **Аналитическое доказательство:**  
     Возведем обе части в квадрат:
     $$(z - z_1)\overline{(z - z_1)} = (z - z_2)\overline{(z - z_2)}$$
     $$|z|^2 - z\bar{z}_1 - \bar{z}z_1 + |z_1|^2 = |z|^2 - z\bar{z}_2 - \bar{z}z_2 + |z_2|^2$$
     $$(\bar{z}_2 - \bar{z}_1)z + (z_2 - z_1)\bar{z} = |z_2|^2 - |z_1|^2$$
     $$2\operatorname{Re}\left(\overline{(z_2 - z_1)} \cdot \left(z - \frac{z_1 + z_2}{2}\right)\right) = 0$$
     Это уравнение прямой, проходящей через середину отрезка $z_0 = \frac{z_1 + z_2}{2}$ ортогонально направляющему вектору $z_2 - z_1$.

4. **Случай 2: $z_1 = z_2$.**  
   Тогда равенство $|z - z_1| = |z - z_1|$ выполняется тождественно для всех $z \in \mathbb{C}$. В этом случае искомое множество — **вся комплексная плоскость** $\mathbb{C}$.

### Задача 3. Докажите неравенство треугольника для модуля комплексного числа: $|z_1 + z_2| \le |z_1| + |z_2|$

**Доказательство:**
1. Рассмотрим квадрат модуля суммы двух комплексных чисел $z_1, z_2 \in \mathbb{C}$:
   $$|z_1 + z_2|^2 = (z_1 + z_2)\overline{(z_1 + z_2)} = (z_1 + z_2)(\bar{z}_1 + \bar{z}_2)$$

2. Раскрываем скобки:
   $$|z_1 + z_2|^2 = z_1\bar{z}_1 + z_1\bar{z}_2 + z_2\bar{z}_1 + z_2\bar{z}_2$$
   Так как $z_1\bar{z}_1 = |z_1|^2$, $z_2\bar{z}_2 = |z_2|^2$, а $z_2\bar{z}_1 = \overline{z_1\bar{z}_2}$:
   $$|z_1 + z_2|^2 = |z_1|^2 + |z_2|^2 + (z_1\bar{z}_2 + \overline{z_1\bar{z}_2})$$

3. Сумма любого комплексного числа и его сопряженного равна удвоенной действительной части: $w + \bar{w} = 2\operatorname{Re}(w)$. Полагая $w = z_1\bar{z}_2$:
   $$|z_1 + z_2|^2 = |z_1|^2 + |z_2|^2 + 2\operatorname{Re}(z_1\bar{z}_2)$$

4. Для любого комплексного числа $w = x + iy$ верно неравенство $\operatorname{Re}(w) = x \le \sqrt{x^2 + y^2} = |w|$.  
   Следовательно:
   $$\operatorname{Re}(z_1\bar{z}_2) \le |z_1\bar{z}_2| = |z_1| \cdot |\bar{z}_2| = |z_1| \cdot |z_2|$$

5. Подставляя эту оценку:
   $$|z_1 + z_2|^2 \le |z_1|^2 + |z_2|^2 + 2|z_1||z_2| = (|z_1| + |z_2|)^2$$

6. Обе части неравенства неотрицательны ($|z_1 + z_2| \ge 0$ и $|z_1| + |z_2| \ge 0$), поэтому извлечение арифметического квадратного корня сохраняет знак неравенства:
   $$|z_1 + z_2| \le |z_1| + |z_2| \quad \blacksquare$$

**Условие равенства:**
Равенство достигается тогда и только тогда, когда $\operatorname{Re}(z_1\bar{z}_2) = |z_1\bar{z}_2|$, что равносильно тому, что $z_1\bar{z}_2$ — неотрицательное вещественное число ($z_1\bar{z}_2 \ge 0$). Если $z_2 \ne 0$, это означает, что $\frac{z_1}{z_2} = \frac{z_1\bar{z}_2}{|z_2|^2} \ge 0$, то есть $z_1 = \lambda z_2$ при некотором $\lambda \ge 0$ (векторы сонаправлены).

### Задача 4. Докажите тождество параллелограмма: $|z_1 + z_2|^2 + |z_1 - z_2|^2 = 2(|z_1|^2 + |z_2|^2)$. Почему оно так называется?

**Доказательство:**
1. Распишем каждый квадрат модуля через произведение на сопряженное число:
   $$|z_1 + z_2|^2 = (z_1 + z_2)\overline{(z_1 + z_2)} = (z_1 + z_2)(\bar{z}_1 + \bar{z}_2) = |z_1|^2 + |z_2|^2 + z_1\bar{z}_2 + \bar{z}_1 z_2$$
   $$|z_1 - z_2|^2 = (z_1 - z_2)\overline{(z_1 - z_2)} = (z_1 - z_2)(\bar{z}_1 - \bar{z}_2) = |z_1|^2 + |z_2|^2 - z_1\bar{z}_2 - \bar{z}_1 z_2$$

2. Сложим оба равенства почленно:
   $$|z_1 + z_2|^2 + |z_1 - z_2|^2 = \big(|z_1|^2 + |z_2|^2 + z_1\bar{z}_2 + \bar{z}_1 z_2\big) + \big(|z_1|^2 + |z_2|^2 - z_1\bar{z}_2 - \bar{z}_1 z_2\big)$$
   Смешанные слагаемые взаимно уничтожаются:
   $$|z_1 + z_2|^2 + |z_1 - z_2|^2 = 2|z_1|^2 + 2|z_2|^2 = 2(|z_1|^2 + |z_2|^2) \quad \blacksquare$$

**Почему оно так называется?**
Рассмотрим параллелограмм, построенный на векторах $z_1$ и $z_2$, выходящих из начала координат $0$:
* Длины смежных сторон параллелограмма равны $|z_1|$ и $|z_2|$. Поскольку противоположные стороны параллелограмма равны, сумма квадратов всех четырёх его сторон равна:
  $$|z_1|^2 + |z_2|^2 + |z_1|^2 + |z_2|^2 = 2(|z_1|^2 + |z_2|^2)$$
* Векторы диагоналей параллелограмма равны $d_1 = z_1 + z_2$ (главная диагональ) и $d_2 = z_1 - z_2$ (вторая диагональ).
* Их длины в квадрате равны $|d_1|^2 = |z_1 + z_2|^2$ и $|d_2|^2 = |z_1 - z_2|^2$.
* Тождество утверждает, что сумма квадратов диагоналей параллелограмма равна сумме квадратов всех четырёх его сторон:
  $$d_1^2 + d_2^2 = 2a^2 + 2b^2$$
Это фундаментальная геометрическая теорема евклидовой геометрии, поэтому тождество носит название **тождества параллелограмма**.

### Задача 5. Образ треугольника с вершинами $z_1 = 3$, $z_2 = -1$, $z_3 = 1 + 2i$

Исходный треугольник $T$ имеет вершины:
* $A = z_1 = 3 = (3, 0)$
* $B = z_2 = -1 = (-1, 0)$
* $C = z_3 = 1 + 2i = (1, 2)$

> Заметим, что основание $AB$ лежит на вещественной оси и имеет длину $|3 - (-1)| = 4$. Середина основания — точка $(1, 0)$, а вершина $C$ имеет координаты $(1, 2)$. Таким образом, треугольник $ABC$ — равнобедренный и прямоугольный с прямым углом при вершине $C$:
> $$AC^2 = (3-1)^2 + (0-2)^2 = 8, \quad BC^2 = (-1-1)^2 + (0-2)^2 = 8, \quad AB^2 = 16 = AC^2 + BC^2$$

#### (a) Отображение $z \mapsto z + i$
* **Геометрический смысл:** Параллельный перенос всей комплексной плоскости на вектор $i = (0, 1)$ (сдвиг вверх на $1$ вдоль мнимой оси).
* **Образ треугольника:** Треугольник той же формы и ориентации, сдвинутый на $1$ вверх.
* **Новые вершины:**
  * $A' = 3 + i = (3, 1)$
  * $B' = -1 + i = (-1, 1)$
  * $C' = (1 + 2i) + i = 1 + 3i = (1, 3)$

#### (b) Отображение $z \mapsto z i$
* **Геометрический смысл:** Поскольку $i = e^{i\pi/2}$, умножение на $i$ представляет собой **поворот вокруг начала координат на угол $90^\circ$ ($\frac{\pi}{2}$) против часовой стрелки**.
* **Образ треугольника:** Треугольник, полученный поворотом исходного на $90^\circ$ против часовой стрелки вокруг $(0, 0)$.
* **Новые вершины:**
  * $A' = 3 \cdot i = 3i = (0, 3)$
  * $B' = -1 \cdot i = -i = (0, -1)$
  * $C' = (1 + 2i) \cdot i = i + 2i^2 = -2 + i = (-2, 1)$

#### (c) Отображение $z \mapsto \dfrac{z}{i}$
* **Геометрический смысл:** Так как $\frac{1}{i} = -i = e^{-i\pi/2}$, деление на $i$ представляет собой **поворот вокруг начала координат на угол $90^\circ$ ($\frac{\pi}{2}$) по часовой стрелке** (то есть на $-\frac{\pi}{2}$).
* **Образ треугольника:** Треугольник, полученный поворотом исходного на $90^\circ$ по часовой стрелке вокруг $(0, 0)$.
* **Новые вершины:**
  * $A' = \frac{3}{i} = -3i = (0, -3)$
  * $B' = \frac{-1}{i} = i = (0, 1)$
  * $C' = \frac{1 + 2i}{i} = \frac{1}{i} + 2 = 2 - i = (2, -1)$

#### (d) Отображение $z \mapsto z z_1$, где $z_1 \in \mathbb{C}$ — фиксированное комплексное число
* **Геометрический смысл в общем случае:**
  Запишем $z_1$ в показательной форме: $z_1 = r_1 e^{i\phi_1}$, где $r_1 = |z_1| \ge 0$, $\phi_1 = \arg(z_1)$.
  * Если $z_1 = 0$: весь треугольник сжимается в единственную точку $\{0\}$.
  * Если $z_1 \ne 0$: преобразование является **поворотной гомотетией** с центром в начале координат $(0, 0)$, состоящей из:
    1. Гомотетии (растяжения/сжатия) с коэффициентом $k = |z_1|$;
    2. Поворота на угол $\phi_1 = \arg(z_1)$ против часовой стрелки.
* **Частный случай (если $z_1$ обозначает конкретную вершину треугольника $z_1 = 3$):**  
  Тогда отображение имеет вид $z \mapsto 3z$ — чистая гомотетия с центром в начале координат и коэффициентом $3$.  
  Вершины образа:
  * $A' = 3 \cdot 3 = 9 = (9, 0)$
  * $B' = 3 \cdot (-1) = -3 = (-3, 0)$
  * $C' = 3 \cdot (1 + 2i) = 3 + 6i = (3, 6)$

### Задача 6. Докажите, что $\left|\dfrac{z-a}{1-\bar{a}z}\right| = 1 \iff |z| = 1$. А что можно сказать про $|z|$, если $\left|\dfrac{z-a}{1-\bar{a}z}\right| < 1$?

*(Предполагается $|a| \ne 1$ и $1 - \bar{a}z \ne 0$).*

**Доказательство и анализ:**
1. Вычислим квадраты модулей числителя и знаменателя дроби:
   $$|z - a|^2 = (z - a)\overline{(z - a)} = (z - a)(\bar{z} - \bar{a}) = |z|^2 - a\bar{z} - \bar{a}z + |a|^2$$
   $$|1 - \bar{a}z|^2 = (1 - \bar{a}z)\overline{(1 - \bar{a}z)} = (1 - \bar{a}z)(1 - a\bar{z}) = 1 - a\bar{z} - \bar{a}z + |a|^2|z|^2$$

2. Вычтем квадрат знаменателя из квадрата числителя:
   $$|z - a|^2 - |1 - \bar{a}z|^2 = \big(|z|^2 - a\bar{z} - \bar{a}z + |a|^2\big) - \big(1 - a\bar{z} - \bar{a}z + |a|^2|z|^2\big)$$
   Слагаемые $-a\bar{z} - \bar{a}z$ взаимно уничтожаются:
   $$|z - a|^2 - |1 - \bar{a}z|^2 = |z|^2 + |a|^2 - 1 - |a|^2|z|^2 = (|z|^2 - 1) - |a|^2(|z|^2 - 1) = (|z|^2 - 1)(1 - |a|^2)$$

3. Разделим полученное тождество на положительную величину $|1 - \bar{a}z|^2$:
   $$\left|\frac{z - a}{1 - \bar{a}z}\right|^2 - 1 = \frac{(|z|^2 - 1)(1 - |a|^2)}{|1 - \bar{a}z|^2}$$

#### 1. Первая часть утверждения: $\left|\dfrac{z-a}{1-\bar{a}z}\right| = 1 \iff |z| = 1$
Дробь по модулю равна $1$ тогда и только тогда, когда левая часть тождества равна нулю:
$$\left|\frac{z - a}{1 - \bar{a}z}\right| = 1 \iff \left|\frac{z - a}{1 - \bar{a}z}\right|^2 - 1 = 0 \iff (|z|^2 - 1)(1 - |a|^2) = 0$$
Так как $|a| \ne 1$, множитель $1 - |a|^2 \ne 0$. Следовательно:
$$|z|^2 - 1 = 0 \iff |z|^2 = 1 \iff |z| = 1 \quad \blacksquare$$

#### 2. Вторая часть: Что можно сказать про $|z|$, если $\left|\dfrac{z-a}{1-\bar{a}z}\right| < 1$?
Условие означает, что левая часть тождества строго отрицательна:
$$\left|\frac{z - a}{1 - \bar{a}z}\right|^2 - 1 < 0 \iff (|z|^2 - 1)(1 - |a|^2) < 0$$
Знак произведения определяется величиной $|a|$:
* **Случай 1 (основной, классический автоморфизм единичного круга): $|a| < 1$.**  
  Тогда $1 - |a|^2 > 0$. Чтобы произведение было отрицательным, должно выполняться:
  $$|z|^2 - 1 < 0 \iff |z| < 1$$
  *Вывод:* если точка $a$ лежит внутри единичного круга ($|a| < 1$), то модуль дроби меньше $1$ тогда и только тогда, когда **точка $z$ также лежит строго внутри единичного круга ($|z| < 1$)**.
* **Случай 2: $|a| > 1$.**  
  Тогда $1 - |a|^2 < 0$. Чтобы произведение было отрицательным, должно выполняться:
  $$|z|^2 - 1 > 0 \iff |z| > 1$$
  *Вывод:* если $|a| > 1$, то модуль дроби меньше $1$ тогда и только тогда, когда **$|z| > 1$** (внешность круга переходит внутрь круга).

### Задача 7. Найдите все такие $z \in \mathbb{C}$, что точки $z, z^2, z^3, z^4$ являются четырьмя различными вершинами некоторого параллелограмма на комплексной плоскости (не обязательно по порядку)

**Решение:**
1. Обозначим вершины четырёхугольника: $A = z, \; B = z^2, \; C = z^3, \; D = z^4$.
2. Четыре различные точки комплексной плоскости являются вершинами параллелограмма (в некотором порядке) тогда и только тогда, когда середины противоположных вершин совпадают. Четыре вершины можно разбить на две пары противоположных ровно 3 способами:
   * **Случай 1 (диагонали $AD$ и $BC$):** $z + z^4 = z^2 + z^3$
   * **Случай 2 (диагонали $AC$ и $BD$):** $z + z^3 = z^2 + z^4$
   * **Случай 3 (диагонали $AB$ и $CD$):** $z + z^2 = z^3 + z^4$

3. Кроме того, по условию все 4 точки должны быть **попарно различны** ($z \ne z^2 \ne z^3 \ne z^4$), поэтому $z \ne 0$ и $z$ не может быть корнем из единицы степеней $1, 2, 3$.

4. Разберём каждый случай:

   * **Случай 1:** $z + z^4 = z^2 + z^3$
     $$z^4 - z^3 - z^2 + z = 0 \iff z(z^3 - z^2 - z + 1) = 0$$
     $$z\big(z^2(z - 1) - (z - 1)\big) = z(z - 1)(z^2 - 1) = z(z - 1)^2(z + 1) = 0$$
     Корни: $z = 0, \; z = 1, \; z = -1$.
     * При $z = 0$: $z = z^2 = z^3 = z^4 = 0$ (все точки совпадают).
     * При $z = 1$: $z = z^2 = z^3 = z^4 = 1$ (все точки совпадают).
     * При $z = -1$: точки принимают значения $-1, 1, -1, 1$ (всего две различные точки).  
     Ни один из корней не даёт 4 различных точек.

   * **Случай 2:** $z + z^3 = z^2 + z^4$
     $$z^4 - z^3 + z^2 - z = 0 \iff z(z^3 - z^2 + z - 1) = 0$$
     $$z\big(z^2(z - 1) + (z - 1)\big) = z(z - 1)(z^2 + 1) = 0$$
     Корни: $z = 0, \; z = 1, \; z = i, \; z = -i$.
     * Значения $z = 0$ и $z = 1$ отбрасываются (точки совпадают).
     * **Проверим $z = i$:**
       $$z = i, \quad z^2 = -1, \quad z^3 = -i, \quad z^4 = 1$$
       Точки $i, -1, -i, 1$ попарно различны. Они образуют вершины квадрата с центром в начале координат (сторона $\sqrt{2}$). Квадрат является параллелограммом.
     * **Проверим $z = -i$:**
       $$z = -i, \quad z^2 = -1, \quad z^3 = i, \quad z^4 = 1$$
       Точки $-i, -1, i, 1$ попарно различны и также образуют вершины того же квадрата.

   * **Случай 3:** $z + z^2 = z^3 + z^4$
     $$z^4 + z^3 - z^2 - z = 0 \iff z(z^3 + z^2 - z - 1) = 0$$
     $$z\big(z^2(z + 1) - (z + 1)\big) = z(z + 1)(z^2 - 1) = z(z + 1)^2(z - 1) = 0$$
     Корни: $z = 0, \; z = 1, \; z = -1$. Как уже показано в Случае 1, ни один корень не даёт 4 различных точек.

**Ответ:** $z = i$ и $z = -i$ (то есть $z = \pm i$).

### Задача 8. Динамическая система пар $(x, y) \mapsto (x^2 - y^2, 2xy)$

**Условие:**
Дана упорядоченная пара чисел $(x, y)$. Каждую секунду она преобразуется по правилу $(x, y) \mapsto (x^2 - y^2, 2xy)$. Через минуту пара совпала с исходной. Найдите все возможные значения исходной пары.

**Решение:**
1. Отождествим упорядоченную пару вещественных чисел $(x, y)$ с комплексным числом $z = x + iy \in \mathbb{C}$.
2. Вычислим квадрат числа $z$:
   $$z^2 = (x + iy)^2 = (x^2 - y^2) + 2xyi$$
   Следовательно, правило преобразования пары $(x, y) \mapsto (x^2 - y^2, 2xy)$ в точности эквивалентно возведению комплексного числа в квадрат:
   $$z \mapsto z^2$$

3. Через 1 секунду: $z_1 = z^2$.  
   Через 2 секунды: $z_2 = (z^2)^2 = z^4 = z^{2^2}$.  
   По индукции через $t$ секунд:
   $$z_t = z^{2^t}$$

4. В 1 минуте содержится 60 секунд ($t = 60$). Условие того, что через 60 секунд пара совпала с исходной, означает:
   $$z_{60} = z \iff z^{2^{60}} = z$$

5. Решаем уравнение:
   $$z\left(z^{2^{60} - 1} - 1\right) = 0$$

   Отсюда получаем две группы решений:
   * **Группа 1:** $z = 0$, что соответствует паре:
     $$(x, y) = (0, 0)$$
     *(Действительно, $(0, 0) \mapsto (0, 0)$ в каждую секунду).*

   * **Группа 2:** $z^{2^{60} - 1} = 1$.  
     Это корни степени $N = 2^{60} - 1$ из единицы. По формуле корней из $1$:
     $$z_k = e^{i \frac{2\pi k}{2^{60} - 1}} = \cos\left(\frac{2\pi k}{2^{60} - 1}\right) + i\sin\left(\frac{2\pi k}{2^{60} - 1}\right), \quad k \in \{0, 1, 2, \dots, 2^{60} - 2\}$$
     Соответствующие вещественные пары:
     $$(x_k, y_k) = \left(\cos\left(\frac{2\pi k}{2^{60} - 1}\right), \; \sin\left(\frac{2\pi k}{2^{60} - 1}\right)\right), \quad k = 0, 1, \dots, 2^{60} - 2$$

6. Все эти $2^{60} - 1$ корней лежат на единичной окружности $x^2 + y^2 = 1$ и попарно различны. Вместе с решением $(0, 0)$ общее число возможных исходных пар равно:
   $$1 + (2^{60} - 1) = 2^{60}$$

**Ответ:**  
Пара $(0, 0)$ и все пары вида $\left(\cos\dfrac{2\pi k}{2^{60} - 1}, \; \sin\dfrac{2\pi k}{2^{60} - 1}\right)$, где $k \in \{0, 1, \dots, 2^{60} - 2\}$ (всего $2^{60}$ возможных пар).

### Задача 1 (доп). Точки на единичной окружности с фиксированным расстоянием

**Условие:**
Найдите множество всех точек $z \in \mathbb{C}$, т. ч. $|z| = 1$ и расстояние от точки $z^3 - z$ на комплексной плоскости до точки $-2$ равно 2.

**Решение:**
1. Расстояние от точки $w = z^3 - z$ до точки $-2$ равно $|w - (-2)| = |z^3 - z + 2|$.  
   Условие задачи задаётся системой:
   $$\begin{cases} |z| = 1 \\ |z^3 - z + 2| = 2 \end{cases}$$

2. Пусть $u = z^3 - z$. Тогда второе уравнение имеет вид $|u + 2| = 2$. Возведём его в квадрат:
   $$|u + 2|^2 = (u + 2)(\bar{u} + 2) = |u|^2 + 2(u + \bar{u}) + 4 = 4$$
   $$|u|^2 + 4\operatorname{Re}(u) = 0$$

3. Так как $|z| = 1$, запишем $z$ в показательной форме: $z = e^{i\theta}$, $\theta \in [0, 2\pi)$.
   * Вычислим $|u|^2$:
     $$u = z^3 - z = z(z^2 - 1)$$
     $$|u| = |z| \cdot |z^2 - 1| = 1 \cdot |e^{2i\theta} - 1| = |e^{i\theta}(e^{i\theta} - e^{-i\theta})| = |2i\sin\theta| = 2|\sin\theta|$$
     Отсюда:
     $$|u|^2 = 4\sin^2\theta$$

   * Вычислим $\operatorname{Re}(u)$:
     $$u = e^{3i\theta} - e^{i\theta} = (\cos 3\theta - \cos\theta) + i(\sin 3\theta - \sin\theta)$$
     $$\operatorname{Re}(u) = \cos 3\theta - \cos\theta = -2\sin\left(\frac{3\theta + \theta}{2}\right)\sin\left(\frac{3\theta - \theta}{2}\right) = -2\sin(2\theta)\sin\theta$$
     Используя $\sin(2\theta) = 2\sin\theta\cos\theta$:
     $$\operatorname{Re}(u) = -4\cos\theta\sin^2\theta$$

4. Подставим $|u|^2$ и $\operatorname{Re}(u)$ в уравнение $|u|^2 + 4\operatorname{Re}(u) = 0$:
   $$4\sin^2\theta + 4(-4\cos\theta\sin^2\theta) = 0$$
   $$4\sin^2\theta (1 - 4\cos\theta) = 0$$

5. Получаем два случая:
   * **Случай А:** $\sin\theta = 0$.  
     Тогда $\theta = 0$ или $\theta = \pi$.
     * При $\theta = 0 \implies z = 1$:  
       $z^3 - z = 1 - 1 = 0 \implies |0 - (-2)| = 2$ (верно).
     * При $\theta = \pi \implies z = -1$:  
       $z^3 - z = -1 - (-1) = 0 \implies |0 - (-2)| = 2$ (верно).

   * **Случай Б:** $1 - 4\cos\theta = 0 \implies \cos\theta = \dfrac{1}{4}$.  
     Тогда:
     $$\sin^2\theta = 1 - \cos^2\theta = 1 - \frac{1}{16} = \frac{15}{16} \implies \sin\theta = \pm \frac{\sqrt{15}}{4}$$
     Соответствующие точки:
     $$z = \cos\theta + i\sin\theta = \frac{1}{4} \pm i\frac{\sqrt{15}}{4}$$

**Ответ:** Множество состоит из 4 точек: $\left\{ 1, \; -1, \; \dfrac{1}{4} + i\dfrac{\sqrt{15}}{4}, \; \dfrac{1}{4} - i\dfrac{\sqrt{15}}{4} \right\}$.

### Задача 2 (доп). Сумма трех точек на единичной окружности

**Условие:**
Пусть для чисел $z_1, z_2, z_3$, лежащих на единичной окружности ($|z_1| = |z_2| = |z_3| = 1$), оказалось, что их сумма тоже лежит на единичной окружности ($|z_1+z_2+z_3| = 1$). Верно ли, что среди $z_1, z_2, z_3$ непременно найдется пара противоположных комплексных чисел (то есть чисел, в сумме дающих 0)?

**Решение:**
**Ответ: ДА, ВЕРНО.**

**Доказательство:**
1. Обозначим элементарные симметрические многочлены от $z_1, z_2, z_3$:
   $$e_1 = z_1 + z_2 + z_3$$
   $$e_2 = z_1 z_2 + z_2 z_3 + z_3 z_1$$
   $$e_3 = z_1 z_2 z_3$$

2. Так как $|z_k| = 1$ для каждого $k \in \{1, 2, 3\}$, то $\bar{z}_k = \dfrac{1}{z_k}$. Вычислим сопряженное к сумме $e_1$:
   $$\bar{e}_1 = \bar{z}_1 + \bar{z}_2 + \bar{z}_3 = \frac{1}{z_1} + \frac{1}{z_2} + \frac{1}{z_3} = \frac{z_2 z_3 + z_1 z_3 + z_1 z_2}{z_1 z_2 z_3} = \frac{e_2}{e_3}$$
   Отсюда:
   $$e_2 = \bar{e}_1 \cdot e_3$$

3. По условию $|e_1| = |z_1 + z_2 + z_3| = 1$. Тогда:
   $$e_1 \bar{e}_1 = |e_1|^2 = 1$$

4. Умножим равенство $e_2 = \bar{e}_1 e_3$ на $e_1$:
   $$e_1 e_2 = (e_1 \bar{e}_1) e_3 = 1 \cdot e_3 = e_3$$
   Следовательно:
   $$e_1 e_2 - e_3 = 0$$

5. Рассмотрим тождество разложения произведения попарных сумм через элементарные симметрические многочлены:
   $$(z_1 + z_2)(z_2 + z_3)(z_3 + z_1) = (z_1 + z_2 + z_3)(z_1 z_2 + z_2 z_3 + z_3 z_1) - z_1 z_2 z_3 = e_1 e_2 - e_3$$

6. Так как $e_1 e_2 - e_3 = 0$, получаем:
   $$(z_1 + z_2)(z_2 + z_3)(z_3 + z_1) = 0$$

7. Поле комплексных чисел $\mathbb{C}$ не содержит делителей нуля. Произведение трех сомножителей равно нулю тогда и только тогда, когда хотя бы один из сомножителей равен нулю:
   $$z_1 + z_2 = 0 \quad \text{или} \quad z_2 + z_3 = 0 \quad \text{или} \quad z_3 + z_1 = 0$$
   Это означает, что среди чисел $z_1, z_2, z_3$ обязательно присутствует пара противоположных комплексных чисел. $\blacksquare$

### Задача 3 (доп). Корни полиномиального уравнения на единичной окружности

**Условие:**
Верно ли, что все корни уравнения $11z^{10} + 10iz^9 + 10iz - 11 = 0$ лежат на единичной окружности?

**Решение:**
**Ответ: ДА, ВЕРНО.**

**Доказательство:**
1. Перепишем уравнение, сгруппировав степени:
   $$11z^{10} + 10iz^9 = 11 - 10iz$$
   $$z^9 (11z + 10i) = 11 - 10iz$$

2. Проверим, может ли $11z + 10i = 0$:  
   Если $11z + 10i = 0$, то $z = -\frac{10i}{11}$.  
   Подставим это значение в правую часть:
   $$11 - 10i\left(-\frac{10i}{11}\right) = 11 - \frac{100}{11} = \frac{21}{11} \ne 0$$
   При этом левая часть равна $z^9 \cdot 0 = 0 \ne \frac{21}{11}$.  
   Значит, $11z + 10i \ne 0$, и мы можем разделить обе части на $11z + 10i$:
   $$z^9 = \frac{11 - 10iz}{11z + 10i}$$

3. Возьмем модуль от обеих частей равенства:
   $$|z|^9 = \left|\frac{11 - 10iz}{11z + 10i}\right|$$

4. Сравним квадраты модулей числителя и знаменателя:
   $$|11 - 10iz|^2 = (11 - 10iz)(11 + 10i\bar{z}) = 121 + 110i\bar{z} - 110iz + 100|z|^2$$
   $$|11z + 10i|^2 = (11z + 10i)(11\bar{z} - 10i) = 121|z|^2 - 110iz + 110i\bar{z} + 100$$
   Вычитаем:
   $$|11 - 10iz|^2 - |11z + 10i|^2 = (121 + 100|z|^2) - (121|z|^2 + 100) = 21 - 21|z|^2 = 21(1 - |z|^2)$$

5. Исследуем возможные значения $|z|$:
   * **Предположим, что $|z| > 1$:**  
     Тогда $1 - |z|^2 < 0 \implies |11 - 10iz|^2 < |11z + 10i|^2 \implies \left|\dfrac{11 - 10iz}{11z + 10i}\right| < 1$.  
     Однако левая часть равенства $|z|^9 > 1$ при $|z| > 1$. Равенство числа строго больше 1 числу строго меньше 1 невозможно. Противоречие.

   * **Предположим, что $|z| < 1$:**  
     Тогда $1 - |z|^2 > 0 \implies |11 - 10iz|^2 > |11z + 10i|^2 \implies \left|\dfrac{11 - 10iz}{11z + 10i}\right| > 1$.  
     Однако левая часть равенства $|z|^9 < 1$ при $|z| < 1$. Равенство числа строго меньше 1 числу строго больше 1 невозможно. Противоречие.

6. Следовательно, единственная оставшаяся возможность:
   $$|z| = 1$$
   При $|z| = 1$ имеем $|z|^9 = 1$ и $\left|\frac{11 - 10iz}{11z + 10i}\right| = 1$, что непротиворечиво.

Таким образом, каждый из корней данного уравнения по модулю равен 1, то есть лежит на единичной окружности. $\blacksquare$

### Задача 4 (доп). Многочлены с функциональным уравнением $P(z)P(z + 1) = P(z^2 + z + 1)$

**Условие:**
Найдите все многочлены $P(z)$ с комплексными коэффициентами, для которых выполнено:
$$P(z)P(z + 1) = P(z^2 + z + 1)$$

**Решение:**
1. **Константные многочлены:**  
   Пусть $P(z) \equiv c \in \mathbb{C}$.  
   Тогда $c \cdot c = c \iff c^2 = c \iff c(c - 1) = 0$.  
   Получаем два решения:
   $$P(z) \equiv 0 \quad \text{и} \quad P(z) \equiv 1$$

2. **Неконстантные многочлены:**  
   Пусть $\deg P = n \ge 1$, и старший член $P(z)$ равен $a_n z^n$ ($a_n \ne 0$).  
   * Старший член левой части $P(z)P(z+1)$ равен $(a_n z^n)(a_n z^n) = a_n^2 z^{2n}$.
   * Старший член правой части $P(z^2 + z + 1)$ равен $a_n (z^2)^n = a_n z^{2n}$.
   Сравнивая коэффициенты при наивысшей степени $z^{2n}$, получаем $a_n^2 = a_n \implies a_n = 1$ (так как $a_n \ne 0$).  
   Следовательно, многочлен $P(z)$ — унитарный (со старшим коэффициентом $1$).

3. **Исследование корней многочлена:**  
   Пусть $\alpha \in \mathbb{C}$ — корень $P(z)$, то есть $P(\alpha) = 0$.  
   * Подставим $z = \alpha$ в уравнение:
     $$P(\alpha^2 + \alpha + 1) = P(\alpha)P(\alpha + 1) = 0 \cdot P(\alpha + 1) = 0$$
     Значит, если $\alpha$ — корень, то $f(\alpha) = \alpha^2 + \alpha + 1$ также является корнем.
   * Итерируя отображение $f$, получаем последовательность корней: $\alpha_0 = \alpha$, $\alpha_{k+1} = \alpha_k^2 + \alpha_k + 1$.  
     Поскольку ненулевой многочлен имеет лишь конечное число корней, множество $\{\alpha_k\}$ обязано быть конечным. Значит, точка $\alpha$ должна быть периодической точкой отображения $f(z) = z^2 + z + 1$.

   * Найдём неподвижные точки отображения $f(z)$:
     $$z^2 + z + 1 = z \iff z^2 + 1 = 0 \iff z = \pm i$$
     Точки $i$ и $-i$ являются неподвижными точками:
     $$f(i) = i^2 + i + 1 = -1 + i + 1 = i$$
     $$f(-i) = (-i)^2 + (-i) + 1 = -1 - i + 1 = -i$$

4. **Проверка базового квадратичного многочлена $P(z) = z^2 + 1$:**  
   Корнями $z^2 + 1$ являются в точности $i$ и $-i$.  
   Проверим выполнение уравнения:
   * Левая часть:
     $$P(z)P(z+1) = (z^2 + 1)((z+1)^2 + 1) = (z^2 + 1)(z^2 + 2z + 2) = z^4 + 2z^3 + 3z^2 + 2z + 2$$
   * Правая часть:
     $$P(z^2 + z + 1) = (z^2 + z + 1)^2 + 1 = (z^4 + 2z^3 + 3z^2 + 2z + 1) + 1 = z^4 + 2z^3 + 3z^2 + 2z + 2$$
   Части тождественно равны! Значит, $P(z) = z^2 + 1$ является решением.

5. **Произвольные степени:**  
   Для любого целого $m \ge 0$ многочлен $P_m(z) = (z^2 + 1)^m$ также удовлетворяет уравнению:
   $$P_m(z)P_m(z+1) = \big[(z^2+1)((z+1)^2+1)\big]^m = \big[(z^2+z+1)^2+1\big]^m = P_m(z^2+z+1)$$

6. **Доказательство единственности:**  
   Представим любой унитарный многочлен-решение в виде $P(z) = (z^2 + 1)^m Q(z)$, где $Q(z)$ не делится на $z^2 + 1$.  
   Тогда $Q(z)$ также обязан удовлетворять $Q(z)Q(z+1) = Q(z^2+z+1)$.  
   Если $\deg Q \ge 1$, то $Q$ имеет хотя бы один корень $\beta \ne \pm i$.  
   Заметим, что $z^2 + z + 1 = \left(z + \frac{1}{2}\right)^2 + \frac{3}{4}$.  
   Если рассмотреть прообразы корней: для любого корня $w$ уравнения $Q(w) = 0$, решения уравнения $z^2 + z + 1 = w$ обязаны быть корнями $Q(z)Q(z+1) = 0$. Для $w = \pm i$ прообразы распадаются ровно на корни $\pm i$ и их сдвиги, которые уже содержатся в корнях $(z^2+1)$. Для любого другого корня дерево прообразов порождает бесконечное число различных корней, что противоречит конечности степени многочлена $Q(z)$.  
   Следовательно, $Q(z) \equiv 1$.

**Ответ:**  
$P(z) \equiv 0$ и $P(z) = (z^2 + 1)^m$ для всех целых $m \ge 0$ (при $m = 0$ получается $P(z) \equiv 1$).

### Задача 5 (доп). Точка Торричелли — Ферма

**Условие:**
Найдите наименьшее значение выражения $|z - 1| + |z - 3i| + |z - (5 + 4i)|$, $z \in \mathbb{C}$.

**Решение:**
1. Обозначим точки на плоскости:
   * $A = 1 = (1, 0)$
   * $B = 3i = (0, 3)$
   * $C = 5 + 4i = (5, 4)$
   Требуется минимизировать сумму расстояний от точки $P(z)$ до вершин треугольника $ABC$:
   $$f(z) = |z - A| + |z - B| + |z - C| = PA + PB + PC$$
   Это классическая задача о **точке Торричелли — Ферма**.

2. Найдём длины сторон треугольника $ABC$:
   * $c^2 = AB^2 = (0 - 1)^2 + (3 - 0)^2 = 1 + 9 = 10 \implies c = \sqrt{10}$
   * $a^2 = BC^2 = (5 - 0)^2 + (4 - 3)^2 = 25 + 1 = 26 \implies a = \sqrt{26}$
   * $b^2 = AC^2 = (5 - 1)^2 + (4 - 0)^2 = 16 + 16 = 32 \implies b = \sqrt{32} = 4\sqrt{2}$

3. Проверим углы треугольника $ABC$ по теореме косинусов:
   * $\cos \angle A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{32 + 10 - 26}{2 \cdot 4\sqrt{2} \cdot \sqrt{10}} = \frac{16}{8\sqrt{20}} = \frac{2}{2\sqrt{5}} = \frac{1}{\sqrt{5}} > 0 \implies \angle A \approx 63.4^\circ < 120^\circ$
   * $\cos \angle B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{26 + 10 - 32}{2\sqrt{26}\sqrt{10}} = \frac{4}{2\sqrt{260}} = \frac{2}{\sqrt{260}} > 0 \implies \angle B < 90^\circ < 120^\circ$
   * $\cos \angle C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{26 + 32 - 10}{2\sqrt{26}\cdot 4\sqrt{2}} = \frac{48}{8\sqrt{52}} = \frac{6}{\sqrt{52}} > 0 \implies \angle C < 90^\circ < 120^\circ$

   Все углы треугольника строго меньше $120^\circ$. Следовательно, точка Торричелли — Ферма $T$ лежит **строго внутри треугольника $ABC$**, и из неё все стороны видны под углом $120^\circ$.

4. Согласно классической теореме Торричелли, минимум суммы расстояний равен длине отрезка $CC'$, где $C'$ — вершина правильного треугольника $ABC'$, построенного на стороне $AB$ **наружу** от треугольника $ABC$.

   Квадрат длины этого отрезка выражается универсальной формулой через стороны и площадь исходного треугольника:
   $$L^2 = \frac{a^2 + b^2 + c^2}{2} + 2\sqrt{3} S_{\triangle ABC}$$

5. Вычислим величины, входящие в формулу:
   * Сумма квадратов сторон:
     $$\frac{a^2 + b^2 + c^2}{2} = \frac{26 + 32 + 10}{2} = \frac{68}{2} = 34$$
   * Площадь треугольника $ABC$:  
     Векторы сторон из вершины $A(1, 0)$:
     $\vec{AB} = (-1, 3)$, $\vec{AC} = (4, 4)$.  
     Площадь равна половине модуля косого произведения:
     $$S_{\triangle ABC} = \frac{1}{2} |(-1) \cdot 4 - 3 \cdot 4| = \frac{1}{2} |-4 - 12| = \frac{1}{2} \cdot 16 = 8$$

6. Находим искомое значение:
   $$L^2 = 34 + 2\sqrt{3} \cdot 8 = 34 + 16\sqrt{3}$$
   $$L = \sqrt{34 + 16\sqrt{3}}$$

**Ответ:** $\sqrt{34 + 16\sqrt{3}}$.

### Задача 6 (доп). Неравенство Хлавачка для трёх комплексных чисел

**Условие:**
Докажите, что для любых трёх комплексных чисел $z_1, z_2, z_3$ справедливо неравенство:
$$|z_1 + z_2| + |z_2 + z_3| + |z_1 + z_3| \le |z_1| + |z_2| + |z_3| + |z_1 + z_2 + z_3|$$
В каком случае достигается равенство?

**Доказательство (через тождество Джоковича):**
Это знаменитое **неравенство Хлавачка (Hlawka's inequality)**.

1. Обозначим:
   $$S = |z_1| + |z_2| + |z_3| + |z_1 + z_2 + z_3|$$
   $$T = |z_1 + z_2| + |z_2 + z_3| + |z_1 + z_3|$$
   $$\Delta = S - T$$
   Требуется доказать, что $\Delta \ge 0$.

2. Воспользуемся тождеством Драгомира Джоковича (D.Ž. Djoković, 1965) для комплексных чисел (и предгильбертовых пространств):
   $$S \cdot \Delta = (|z_1| + |z_2| - |z_1 + z_2|)(|z_1 + z_2 + z_3| + |z_3| - |z_1 + z_2|)$$
   $$+ (|z_2| + |z_3| - |z_2 + z_3|)(|z_1 + z_2 + z_3| + |z_1| - |z_2 + z_3|)$$
   $$+ (|z_3| + |z_1| - |z_3 + z_1|)(|z_1 + z_2 + z_3| + |z_2| - |z_3 + z_1|)$$

3. Оценим каждый сомножитель в трёх слагаемых правой части:
   * По стандартному неравенству треугольника для модулей:
     $$|z_1| + |z_2| - |z_1 + z_2| \ge 0$$
     $$|z_2| + |z_3| - |z_2 + z_3| \ge 0$$
     $$|z_3| + |z_1| - |z_3 + z_1| \ge 0$$
   * Для вторых сомножителей заметим, что $z_1 + z_2 = (z_1 + z_2 + z_3) - z_3$. Применяя неравенство треугольника к разности:
     $$|z_1 + z_2| = |(z_1 + z_2 + z_3) - z_3| \le |z_1 + z_2 + z_3| + |z_3|$$
     Откуда:
     $$|z_1 + z_2 + z_3| + |z_3| - |z_1 + z_2| \ge 0$$
     Аналогично:
     $$|z_1 + z_2 + z_3| + |z_1| - |z_2 + z_3| \ge 0$$
     $$|z_1 + z_2 + z_3| + |z_2| - |z_3 + z_1| \ge 0$$

4. Каждое из трёх слагаемых правой части представляет собой произведение двух неотрицательных чисел. Следовательно, вся правая часть неотрицательна:
   $$S \cdot \Delta \ge 0$$

5. Так как $S = |z_1| + |z_2| + |z_3| + |z_1 + z_2 + z_3| \ge 0$, то:
   * Если $S = 0$, то $z_1 = z_2 = z_3 = 0$, и неравенство тривиально обращается в равенство $0 \le 0$.
   * Если $S > 0$, разделим обе части на $S$ и получим:
     $$\Delta \ge 0 \iff |z_1 + z_2| + |z_2 + z_3| + |z_1 + z_3| \le |z_1| + |z_2| + |z_3| + |z_1 + z_2 + z_3| \quad \blacksquare$$

---

**Условие достижения равенства:**
Равенство достигается тогда и только тогда, когда каждое из трёх слагаемых тождества Джоковича равно нулю. Это происходит в следующих и только следующих случаях:

1. **Хотя бы одно из чисел равно нулю** (например, $z_1 = 0$, тогда неравенство принимает вид $|z_2| + |z_2 + z_3| + |z_3| \le |z_2| + |z_3| + |z_2 + z_3|$, что является тождеством).
2. **Все три числа лежат на одном луче**, выходящем из начала координат (то есть имеют одинаковый аргумент: $\arg z_1 = \arg z_2 = \arg z_3$, или $z_1, z_2, z_3$ попарно сонаправлены: $z_1 = \lambda z_2 = \mu z_3$ при $\lambda, \mu \ge 0$).
3. **Сумма всех трёх чисел равна нулю**:
   $$z_1 + z_2 + z_3 = 0$$
   *(Действительно, в этом случае $z_1 + z_2 = -z_3$, $z_2 + z_3 = -z_1$, $z_1 + z_3 = -z_2$, откуда левая часть равна $|-z_3| + |-z_1| + |-z_2| = |z_1| + |z_2| + |z_3|$, а правая часть равна $|z_1| + |z_2| + |z_3| + 0$, то есть равенство выполняется тождественно).*
