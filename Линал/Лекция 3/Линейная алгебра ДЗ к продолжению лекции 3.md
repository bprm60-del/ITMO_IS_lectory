## Задача 1: Деление многочленов с остатком и теорема Безу

1. Выполните деление «уголком» многочлена $A(x) = 2x^4 - 3x^3 + 4x^2 - 5x + 6$ на $B(x) = x^2 - 3x + 1$ в $\mathbb{R}[x]$. Найдите частное $Q(x)$ и остаток $R(x)$.
2. Не выполняя деления уголком, найдите остаток от деления многочлена $P(x) = x^{2026} - 3x^{100} + 5x^2 - 7$ на $(x - 1)$ и на $(x + 1)$.

## Задача 2: Комплексные корни и кратность

1. Найдите все комплексные корни многочлена $P(x) = x^4 + 4$ и разложите его:
   * над полем комплексных чисел $\mathbb{C}$ (на 4 линейных множителя);
   * над полем вещественных чисел $\mathbb{R}$ (на 2 неприводимых квадратных трехчлена).
   *(Подсказка: используйте метод добавления и вычитания $4x^2$: $x^4 + 4 = (x^2 + 2)^2 - 4x^2$).*
2. Определите кратность корня $c = 1$ для многочлена $P(x) = x^5 - 5x^4 + 10x^3 - 10x^2 + 5x - 1$.

## Задача 3: Доказательство обобщенной теоремы Виета

### Формулировка:
Докажите формулы Виета для произвольного многочлена $n$-й степени:
$$P(x) = a_n \prod_{k=1}^n (x - c_k) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_0$$

### Подсказки к доказательству:
1. Раскройте скобки в произведении $(x - c_1)(x - c_2) \dots (x - c_n)$ с помощью комбинаторного правила: для каждого слагаемого из каждой скобки $(x - c_k)$ выбирается либо $x$, либо $-c_k$.
2. При сборе коэффициента перед $x^{n-k}$ ровно из $k$ скобок берутся элементы $-c_i$, а из оставшихся $n-k$ скобок берутся $x$.
3. Умножьте результат на $a_n$ и приравняйте коэффициенты при одинаковых степенях $x^k$.
